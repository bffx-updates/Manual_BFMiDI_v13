1.1. Connecting with your phone — illustrated step by step
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: FROM WIFI TO THE EDITOR — 4 STEPS
Purpose: The complete path in 4 steps, with drawings: connect to the pedal's WiFi, type the
          password, open the browser and you're done. Nothing to install — if you can join a WiFi
          network, you can use the editor.
How to:
1. Turn on the pedal and grab your phone. Open Settings › Wi-Fi (where you always join networks).
2. In the network list, tap BFMIDI_WIFI — it's the network the pedal itself creates.
3. Type the password bfmidi@editor and confirm. If the phone warns the network “has no internet”,
   that's expected — stay connected (the editor lives in the pedal, not on the internet).
4. Open the browser (Chrome, Safari or Edge), type 192.168.4.1 in the address bar and confirm — the
   editor opens instantly.
Fields and items:
- Step 1 — The pedal's network (WiFi)
  Description: With the pedal on, the BFMIDI_WIFI network shows up in the phone's Wi-Fi list, next
             to your home networks. Tap it. Not showing? The pedal's WiFi turns itself off after 90
             s with nobody connected. To bring it back, power the controller off and on — WiFi comes
             up at boot. If you'd rather have a foot shortcut, set up a combo with the WIFI ON/OFF
             action in GLOBAL › BANKS.
- Step 2 — The password (password)
  Description: The password is always bfmidi@editor (all lowercase). After connecting, the phone may
             complain the network “has no internet access” — that's normal and expected: choose
             “keep connection”. You're not browsing the internet, you're talking to the pedal.
- Step 3 — The address (browser)
  Description: In the browser, type 192.168.4.1 straight into the address bar (at the top, where
             websites appear) — just numbers and dots, no “www” or “https”. If the browser tries to
             search instead of opening it, type http://192.168.4.1.
- Step 4 — The editor (app)
  Description: The editor loads instantly, straight from the pedal. Tip: use the browser's “Add to
             Home Screen” to create an app-like shortcut — next time it's a single tap.
Notes:
- Works the same on a tablet or computer — just join the same WiFi and open the same address.
- This path uses the pedal's own network (AP mode). To use the pedal on your home network, see the
   next card.

1.2. From zero to the editor open
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › CONEXÕES › WI-FI — CONNECTION
Purpose: The BFMiDi editor runs inside the controller itself — nothing to install. You connect to

How to:
1. Requirements: a device with WiFi and a modern browser (Chrome, Edge or Safari). That's it.

3. First access: on your device, connect to the BFMIDI_WIFI network (password bfmidi@editor) and
   open http://192.168.4.1 in the browser — the editor loads instantly.

Fields and items:
- Connection state (status)
  Description: Educational card with the 4 possible scenarios, the current one highlighted: no WiFi
             (connect to the BFMIDI_WIFI network, password bfmidi@editor, and go to
             http://192.168.4.1), direct AP (your device on the pedal's network), router (pedal on
             your home network) and USB (cable).
- Connection status (status)
  Description: Summary of the current mode: AP only · 192.168.4.1 when the pedal is only on its own

- SSID (network) (selection)
  Description: Target WiFi network. Choose from the list filled by SCAN or type the name (hidden

- Password (password)
  Description: Password for the chosen network. It is kept in the controller's protected memory.

  Description: Searches for nearby networks (available when connected by AP or USB).

  Description: Applies and saves the credentials. Only 2.4 GHz networks are supported.

  Description: Result of the scan with signal strength; tapping a network fills in the SSID.

- Full network details in the section SYSTEM Page › Connections › Wi-Fi (Full Manual).

1.3. Android app (APK)
~~~~~~~~~~~~~~~~~~~~~~
Purpose: On Android there's a dedicated app (APK) that opens the editor fullscreen, like a real app
          — no browser bar. The screen ships inside the app; it talks to the pedal over WiFi. On
          iPhone you don't need an APK: use Safari's “Add to Home Screen”.
How to:
1. Download the app: download BFMiDi for Android (APK). The link always gives you the latest
   version.
2. Install: open the downloaded file. Android will ask you to allow “install apps from unknown
   sources” — allow it once. The BFMiDi icon appears in your app drawer.
3. Use it: connect your phone to the pedal's WiFi (network BFMIDI_WIFI, password bfmidi@editor) and

- The app is the same editor that runs in the browser — just embedded, so it loads instantly and
   opens fullscreen.
- iPhone/iPad: there's no APK. Open 192.168.4.1 in Safari and use “Add to Home Screen” — it works
   just like an app.

TOPIC 2 - MY FIRST PRESET
----------------------------------------------------------------------------------------
Page: 1
Summary: In 4 simple steps: what a preset is, telling the effects unit which sound to load, saving
        and testing.
Introduction: Let's build your first preset in the simplest way possible. Think of it like this:
        your effects unit (e.g. the Ampero) already has several sounds saved; the BFMiDi is the
        remote control that, with a tap of your foot, makes the effects unit jump to whatever sound
        you want. Each example below uses the Ampero, but it works with any effects unit.

2.1. Setup Wizard — the guided path
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: WIZARD — ONE QUESTION PER SCREEN
Purpose: If you've never dealt with MIDI, start here. The wizard asks one question per screen, in
          plain language, and by the end the preset is built — including the LIVE mode footswitches.
          You don't need to know what CC, PC or channel mean to get to the end.
How to:
1. On the PRESET page, at the bottom of the MAIN card, tap WIZARD.
2. Answer the questions in order: which pedal you have → which preset you want to build → its name →
   which sound it calls → and then LIVE mode, one footswitch at a time.
3. On the preset step, step on the footswitch you want to set up — the controller figures out which
   one you chose.
4. Follow it to the end. Each footswitch finishes with a recap, showing the preset taking shape.
Fields and items:
- Step 1 — Which pedal you have (choice)
  Description: You pick your device from a searchable list (Ampero, Kemper, GP-5, HX Stomp…). That's
             what turns on Friendly Mode: from then on, instead of numbers, the editor shows
             commands by name — “Drive”, “Delay”, “Reverb”.
             Can't find yours? Choose GENERIC and carry on; everything still works, just with
             numbers.
- Step 2 — Step on the footswitch (gesture)
  Description: Instead of choosing “bank A, preset 3” from a list, you simply step on the footswitch
             you want to configure — and the wizard continues with that one.
             To do that it puts the controller in PRESET mode for a moment: that's the mode where
             stepping changes preset (in LIVE, your foot does whatever the preset assigned it).
- Steps 3 and 4 — Name and sound (fields)
  Description: The name is the label shown on the controller's display — usually the song's name.
             The sound is which preset of your effects unit this button will call. With Friendly
             Mode on, it appears with the name the unit uses (on the Ampero, A01-1, A01-2…) instead
             of a bare number.
- Step 5 — What LIVE mode is (explanation)
  Description: A screen that asks nothing: it just explains, with a drawing, the difference between
             PRESET (each foot calls up a song) and LIVE (each foot becomes an effect pedal inside
             that song).
             It exists because “LIVE mode” means nothing to someone building their first preset —
             without the explanation, the next question (“what does FOOT 1 do?”) arrives with no
             context.
- Step 6 — One footswitch at a time (sequence)
  Description: For each footswitch the wizard asks, one screen at a time: the behaviour → the
             command → the LED colour → the initial state → the on-screen colour → icon and name.
             That's six questions for ON/OFF and five for the rest — only ON/OFF has an on/off state
             (TAP is a rhythm; ONE COMMAND always sends the same thing).
             Nothing is stored along the way: only each footswitch's last screen saves.
- The four behaviours offered (choice)
  Description: ON / OFF — the most common: your foot switches an effect on and off, like a real
             pedal. TAP TEMPO — you tap the tempo with your foot. ONE COMMAND — every tap sends the
             same thing. NOTHING — the footswitch is left with no function.
             It's a deliberate subset: four of the controller's ten modes. If you want SPIN, RAMP,
             MACROS, STEPS or CONTROL, use the normal editor afterwards — the wizard is the front
             door, not the ceiling.
- Two colours, two screens (detail)
  Description: The LED ring colour (what your foot finds without looking) and the on-screen tile
             colour are different things — hence two questions.
             To save you work, the screen colour follows the LED one until you touch it: if you just
             click through, you end with both matching, and if you want them different, the option
             is there.
- Initial state (ON/OFF only) (choice)
  Description: Does the effect come in already on when you call up the song, or does it wait for you
             to step on it?
             It's not decoration: with send-on-preset-call enabled (the default), the answer changes
             what goes out the MIDI cable along with the preset — not just the LED colour.
Notes:
- The wizard doesn't undo fine-tuning you've already done in the editor: when it saves the
   footswitch's display, it touches the label, the icon and the on-state colour, leaving the rest as
   it was.
- You can quit halfway and come back later through the normal editor — whatever was saved stays
   saved.
- Prefer to go straight in? The next card shows the same path by hand, in 4 steps.

2.2. The whole path — illustrated step by step
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: FROM THE APP TO YOUR FOOT — 4 STEPS
Purpose: The 4 steps of your first preset in a single drawing: choose the preset in the app, tell
          the effects unit which sound to load, save and step on it. Tap the numbers on the drawing
          for each step's details.
How to:
1. On the app's PRESET page, tap button 1 (bank A) — it gets an orange border.
2. In the MAIN card, choose the PC (your effects unit's sound — on the Ampero that's A01-1, A01-2…),
   check the channel (when in doubt, 1) and give it a name.
3. Tap SAVE — nothing is stored before that.
4. Step on the controller's footswitch 1: the effects unit jumps to the chosen sound. Repeat for
   buttons 2, 3, 4…
Fields and items:
- Step 1 — Choose the preset (app)
  Description: The BFMiDi has 10 banks (A–J) with 6 presets each — 10 pages with 6 shortcuts. You're
             going to edit the shortcut of button 1 in bank A: tap it on the PRESET page and
             everything you change below applies to it.
- Step 2 — The sound (PC) and the channel (fields)
  Description: PC is the sound's number on your effects unit — the same one shown on its display.
             CHANNEL is "which device listens" (most use 1). The name is just a label for the BFMiDi
             display. With Friendly Mode on (GLOBAL › MIDI), the PC shows up by the sound's name
             instead of the number.
- Step 3 — Save (action)
  Description: The SAVE button sits on the app's bottom bar. Without saving, the change is lost when
             you switch presets.
- Step 4 — Step on it and test (test)
  Description: You step on footswitch 1 → the BFMiDi sends the PC through the MIDI cable → the
             effects unit switches to the sound. Didn't switch? Check the MIDI channel and that the
             cable runs from the BFMiDi to the effects unit (MIDI OUT → MIDI IN).
Notes:
- Want to turn effects on and off with your foot (like real pedals)? That's LIVE MODE — see the next
   card.

2.3. LIVE MODE (optional) — Turn effects on and off with your foot
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SW1 · STOMP
Purpose: Besides calling up the sound, each footswitch can become a "pedal" that turns an effect of
          that preset on/off — that's LIVE MODE. You can leave it for later; the 4 steps above
          already get you playing.
How to:
1. At the top of the page, switch the toggle from PRESET MODE to LIVE MODE.
2. Tap SW1 and choose the STOMP mode (on/off).
3. Tell it which effect it controls: the effect's CC (e.g. the drive) and the effects unit's
   channel. With Friendly Mode, choose by name.
4. In the Options card, pick the switch's LED color, leave Fires on preset on (it's the default) and
   set whether the effect Starts ON or OFF — details in the fields below.
5. Save. Now, inside LIVE, stepping on SW1 turns that effect on and off — like a real pedal.
Fields and items:
- LED color (color)
  Description: In the Options card (TRIGGER · LED), the LED tile picks that switch's ring color in
             LIVE: lit when the effect is ON, off (or just a dim preview, depending on the option in
             GLOBAL › LEDS) when it's OFF. Use one color per effect type — e.g. red drive, blue
             delay — to find your way on stage.
- Fires on preset (default: on) (switch)
  Description: On (default): when the preset is called, the switch already sends its initial state
             to the effects unit — effect, LED and screen are born in sync. Off = WAITING LIVE MODE:
             nothing is sent on preset load; the effect only fires when you step on the switch
             inside LIVE. Useful when you don't want the preset change to touch that effect.
- Starts ON / OFF (switch)
  Description: The effect's initial state when the preset is called: Starts ON = the preset comes in
             with the effect already on (sends the ON value, LED lit); off = comes in with the
             effect off (default). E.g.: in a song that opens with drive, set the drive SW to Starts
             ON.
Notes:
- Want to understand all the modes (tap tempo, volume, scenes…)? See Footswitch modes in the Full
   Manual.

3.1. What connects where
~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: PHYSICAL CONNECTIONS
Purpose: Select your controller model to view the physical hardware connections. The available ports
          vary by version.
Fields and items:
- Controller model (selection)
  Description: Choose the physical model of your BFMiDi. The connection diagram changes depending on
             the controller, because not all of them have USB Host, EXP, Dual Switch or the same
             connector layout.
             New in v13: the family gained the ESP32-S3 line — the BFMIDI-3 8SW+ (8 footswitches)
             and the BFMIDI-3 NANO+ V2. These boards have a new processor, more memory and more room
             for images and icons. The editor only offers models compatible with the processor of
             the pedal you are connected to, so you cannot pick the wrong board.
- Top/front view (drawing)
  Description: The selected model's panel seen from above: the position of the footswitches (LIVE,
             GLOBAL and SW1–SW6), the display and the indicators. Models without a drawing yet show
             the reserved space.
- Rear/connectors view (drawing)
  Description: The rear panel with the model's physical ports — on the BFMIDI-1 7S: MIDI TRS OUT, 9v
             power (center-negative) and USB DEVICE. Each port is detailed in the fields below.
- USB Device (port)
  Description: The main USB port — the controller appears as a USB MIDI device on the
             computer/tablet. The same port also handles the cable editor (Web Serial, no WiFi) and
             firmware updates through the browser.
- USB Host (port)
  Description: The opposite of the USB Device: here you plug devices INTO the controller — MIDI
             keyboards, another BFMiDi, USB effects units. Managed in the SYSTEM › CONEXÕES › USB
             HOST tab. It comes in two versions: standard USB Host (BFMIDI-2) forwards the connected
             device's MIDI; USB Host Plus (BFMIDI-3) adds the Tonex mode (to control the IK Tonex
             One), reverse MIDI / Control Host (the plugged device controls the BFMiDi) and
             Bluetooth (BLE keyboard).
- MIDI TRS (port)
  Description: MIDI output on a minijack (TRS) connector, for pedals with a compact MIDI input. It
             carries the same signal as the DIN5 output — use the cable/adapter suited to your
             pedal.
- MIDI DIN (port)
  Description: The classic 5-pin MIDI output, for effects units and traditional gear.
- Expression pedal (EXP) (port)
  Description: ("+" models.) Input for an analog expression pedal (TRS) — the movement becomes a
             continuous CC from 0 to 127. Setup and calibration in GLOBAL › MIDI.
- Dual Switch (port)
  Description: ("+" models.) Input for an external dual pedal (2 simple footswitches, no LED) — each
             button gets its own function in GLOBAL › MIDI.
- Power (DC IN) (port)
  Description: The controller's power input. Use the power supply recommended by BFFX — if in doubt,
             check the label next to your device's connector.
Notes:
- The available ports vary by model: standard USB Host on the BFMIDI-2 and Plus (Tonex, reverse
   MIDI, Bluetooth) on the BFMIDI-3; EXP and Dual Switch only on the "+" variants.

Page: 1

Introduction: If you're just starting, skip this section — the whole manual already describes v13.
        It's for those coming from v12 who want to know what moved.
        The good news first: your presets keep working. Nothing you built is lost in the update, and
        old settings are converted automatically to the new format.

4.1. The changes, one by one
~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: V13 — WHAT'S NEW
Purpose: The general overview of what's new. Each item points to the manual section where the
          subject is explained in full.
Fields and items:
- Setup Wizard (new)
  Description: A guided path that builds the whole preset by asking one question per screen, with no
             jargon — including the LIVE mode footswitches. It sits at the bottom of the MAIN card,
             on the PRESET page.
             See: First steps › Setup Wizard.
- Automatic update (new)
  Description: The controller now checks by itself whether a new version is out, and a single button
             — UPDATE EVERYTHING — handles firmware and editor together. No more manually
             downloading a file and flashing by hand.
             See: SYSTEM page › Update.
- Preset Call replaced the bank-change modes (changed)
  Description: The old MODE 1 · HYBRID and MODE 2 · SINGLE are gone. In their place you define the
             action of each footswitch on each gesture (short and long click) — 12 combinations.
             Your old mode is converted automatically, so in practice nothing changes until you
             decide to touch it.
             See: GLOBAL page › Preset Call.
- Combos are no longer fixed (changed)
  Description: There used to be two two-foot shortcuts, the same on every pedal. Now there are nine
             free pairs, each with the action you choose.
             Careful: on a factory pedal no combo comes configured. If you updated, the two old ones
             are kept automatically.
             See: GLOBAL page › Footswitch Combos.
- Two new footswitch modes: STEPS and CONTROL (new)
  Description: STEPS — sequencer: sweeps four values on a CC, looping, at the tempo you tap or type.
             CONTROL — A/B selector: one click alternating two destinations, one always on and the
             other off.
             See: Footswitch modes (LIVE).
- Screen layout per preset (new)
  Description: The screen arrangement used to be global only; now each preset can have its own. If
             you choose nothing, it keeps inheriting the global, as before.
             See: PRESET page › DISPLAY tab.
- Expression pedal per preset (new)
  Description: An extra CC send can carry the EXP value: instead of sending MIDI, it says where the
             expression pedal points while that preset is active.
             See: PRESET page › MAIN card.
- Bluetooth (new)
  Description: On models with the USB Host module, the controller can become a Bluetooth keyboard, a
             wireless MIDI interface, or go looking for a Bluetooth pedal to gain extra
             footswitches.
             See: SYSTEM page › BFMiDi Bluetooth.
- The SYSTEM page was reorganised (changed)
  Description: The tabs became DEVICE · CONNECTIONS · EDITOR · MAINTENANCE. Storage moved to DEVICE,
             Wi-Fi and USB Host became two destinations inside CONNECTIONS, and
             theme/language/auto-save got the EDITOR tab.
             See: SYSTEM page.
- Bank and preset backup (new)
  Description: Besides the whole-pedal backup, you can now save one bank (6 presets with the media
             they use) or a single preset — the practical way to swap a set with someone else.
             See: SYSTEM page › Three backup scopes.
- Name font size (new)
  Description: Each footswitch's label can have a fixed size (9, 12, 18 or 24 pt) instead of
             automatic — handy to keep it readable from a distance.
             See: Footswitch modes › DISPLAY tab.
- New models (ESP32-S3 line) (new)
  Description: The BFMIDI-3 8SW+ and BFMIDI-3 NANO+ V2 joined the family, with a new processor, more
             memory and twice the image and icon slots.
             See: Hardware.

4.2. Two points that need attention after updating
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: BEFORE THE FIRST GIG
Purpose: Almost everything in v13 is an addition, and additions bother nobody. These two items are
          the exception — worth reading before your first gig after updating.
Fields and items:
- 1 — The Wi-Fi foot shortcut (attention)
  Description: In v12, SW2+SW3 turned Wi-Fi on, on any pedal, always. In v13 that became a
             configurable combo — and on a factory pedal no combo comes configured.
             If you updated you keep SW2+SW3 automatically, so nothing is lost. But if you delete
             that combo, or you're on a new pedal, know the alternative: Wi-Fi always comes up when
             you power the controller on and waits 90 seconds. Powering off and on solves it.
             The recommendation: reserve one combo for WI-FI ON/OFF and be done with it.
- 2 — Back up before updating over cable (attention)
  Description: Updating over the USB cable replaces all the pedal's content: presets, images and
             icons return to the factory package. That's expected behaviour — the cable writes the
             entire memory.
             Updating over your network (on models that support it) preserves everything. But since
             you don't always choose which path the editor takes, there's one safe rule: take a full
             backup before any update. It takes seconds.
Notes:
- Apart from those two, the update is uneventful: presets, banks, colours, icons and the global
   configuration cross over with no intervention.

TOPIC 5 - OVERVIEW
----------------------------------------------------------------------------------------
Summary: How the controller works, Friendly Mode and the bank/preset/LIVE concepts.
Introduction: The BFMiDi is a floor MIDI controller (footswitch) with a color screen, an LED ring
        and a built-in editor. It sends MIDI commands (Program Change and Control Change) to effects
        units, multi-effects, amplifiers and software — via DIN5/TRS, via USB and even to devices
        plugged into the controller itself (USB Host, on the BFMIDI-3 models).
        Two things set it apart from ordinary MIDI controllers: the preset + virtual pedals workflow
        (call up your effects unit's preset and, in LIVE, turn its effects on/off as if they were
        pedals) and Friendly Mode, which swaps MIDI numbers for the real names of your device's
        commands. All configuration is done through the web editor (this very interface), which runs
        straight from the pedal — with nothing to install.

5.1. How the controller works (preset + virtual pedals)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: THE WORKFLOW — PRESET ➜ LIVE
Purpose: The BFMiDi workflow is different from ordinary controllers: first you call up a preset on
          your effects unit/stomp; then, entering LIVE mode, each footswitch becomes a "pedal" of
          that active preset — turning effects on and off or changing parameters, as if they were
          individual pedals on a pedalboard.
How to:
1. 1 · Call up the preset: in BANK/PRESET mode, stepping on a switch sends the Program Change (+
   extra messages) that loads the preset on your effects unit — the song's "tone".
2. 2 · Enter LIVE: the same switches become controls of that active preset: a STOMP turns the drive
   on/off, a SPIN cycles through 3 gain levels, a RAMP sweeps the volume… each one plays the role of
   a pedal.
3. 3 · Sync (important!): the sync is not automatic — effects units do not report the state of their
   effects back to the controller. That is why each LIVE SW is customized per preset and is fired
   together with the preset call (the "Fire on preset" + "Starts ON" options): the state of the
   effects and parameters starts out matching exactly what the LED and the screen show.
Fields and items:
- Preset call (concept)
  Description: Stepping on a preset (BANK mode) sends the main PC + extra messages and prepares the
             switch functions. It is the equivalent of "changing the sound" for the song.
- Virtual pedals (LIVE mode) (concept)
  Description: In LIVE, each footswitch performs the function configured for that preset: turning an
             effect on/off (STOMP), cycling through a parameter's values (SPIN), sweeping a value
             (RAMP), tapping tempo (TAP)… Everything operates inside the effects unit's active
             preset — like pedals on a pedalboard.
- Configured sync (not automatic) (concept)
  Description: The effects unit does not report the state of its effects back. The sync comes from
             the configuration: each SW sets its initial state ("Starts ON/OFF") and sends it
             together with the preset call ("Fire on preset"). That way what the LED and the tile
             show is exactly what the effects unit is doing.
Notes:
- If you change an effect directly on the device (outside the controller), the state may diverge
   until the next preset call — call up the preset again to re-sync everything.

5.2. Friendly Mode (Match Mode) — MIDI with names
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: CC SELECTOR — WITH AND WITHOUT FRIENDLY MODE
Purpose: The big advantage when configuring: instead of memorizing PC/CC numbers from your effects
          unit's manual, you pick the device and the editor starts showing the MIDI commands already
          mapped with friendly names.
How to:
1. Pick your device in GLOBAL › MIDI › Friendly Mode (or a device per channel, in MULTIPLE MODE).
2. Done: all the PC and CC selectors in the editor show names ("Stomp A", "Delay On", "Boost")
   instead of raw numbers.
3. The list covers dozens of devices: Ampero, HX Stomp, Kemper Player, Quad Cortex, Tonex, Strymon
   and many others.
Fields and items:
- Named commands (concept)
  Description: The BFMiDi comes with ready-made maps of the MIDI commands for dozens of effects
             units. With the device selected, any PC/CC selector becomes a readable list —
             configuring a switch becomes intuitive, with no need to consult MIDI tables.
- Per channel (MULTIPLE MODE) (concept)
  Description: Have more than one device in your rig? Map one pedal per MIDI channel — each channel

Notes:
- You can hide the unnamed commands ("Omit unnamed PC/CC") — the list then shows only what really
   exists on the device.

5.3. Basic concepts
~~~~~~~~~~~~~~~~~~~
Related screen/preview: HOW THE CONTROLLER IS ORGANIZED
Purpose: Understanding the four core ideas of the controller: banks, presets, operating modes and
          layers.
How to:
1. The memory is organized into 10 banks (letters A–J), each with 6 presets (1–6) — 60 presets in
   total.
2. Each preset stores: a name, a main Program Change, extra MIDI messages and the function of each
   footswitch.
3. In BANK/PRESET mode, the footswitches select presets. In LIVE mode, each footswitch performs the
   function configured on it (turn an effect on/off, tap tempo, etc.).
4. Each preset has 2 layers of functions per footswitch — you can switch between two "sets" of
   functions within the same preset.
Fields and items:
- Bank (A–J) (concept)
  Description: A group of 6 presets identified by a letter. The current letter appears large on the
             screen and on the editor tile. Banks can be enabled/disabled in the GLOBAL > BANKS
             page.
- Preset (1–6) (concept)
  Description: A saved "sound": name, Program Change, MIDI channel, extra messages and the
             footswitch configuration. It is called up by pressing the matching footswitch in BANK
             mode or via the editor.
- PRESET / BANK mode (concept)
  Description: Navigation mode: the footswitches change preset and bank. When calling up a preset,
             the controller sends the configured MIDI (PC + extras + the switches' initial state),
             always in the order MIDI → LED → Screen.
- LIVE mode (concept)
  Description: Performance mode: each footswitch performs its function (STOMP, TAP TEMPO, SPIN…).
             The screen shows one "tile" per switch, with an icon, label and state. You enter it via
             the physical LIVE button (when the board has one), via a switch combo or via the
             editor.
- Layer 1 / Layer 2 (concept)
  Description: Each preset can have two layers of functions per footswitch. Layer 2 is optional
             (enabled in GLOBAL > LEDS > Dedicated) and is toggled with the LIVE button during
             performance. The active layer is not saved — when powered back on, it returns to layer
             1.
- PC (Program Change) (MIDI)
  Description: A MIDI message that changes the "program"/preset of the target device. 0–127 on its
             own, or larger values combined with Bank Select (MSB/LSB) — the BFMiDi handles the
             translation automatically.
- CC (Control Change) (MIDI)
  Description: A continuous-control MIDI message: a control number 0–127 and a value 0–127. Used to
             turn effects on/off, adjust volume, wah, etc.
- MIDI channel (MIDI)
  Description: The "address" of the target device, from 1–16. Each piece of gear listens on one
             channel. On the BFMiDi, channel 0 / MUTE means "this message is disabled".
Examples:
- Show com pedaleira: banco A = músicas 1–6 do set. Preset A1 manda PC 12 (timbre clean) no canal 1;
   em LIVE, SW1 liga o drive (CC 49), SW2 o delay (CC 51), SW3 é tap tempo.
- Layer 2: camada 1 com os efeitos da música; camada 2 com utilidades (afinador, boost, cena
   alternativa).
Notes:
- 4-switch boards (the "4S" and "MICRO" models) show and edit only SW1–SW4.
- On the NANO models, SW6 can become an independent global switch (SYSTEM > PRINCIPAL).

TOPIC 6 - PRESET PAGE
----------------------------------------------------------------------------------------
Summary: Select banks and presets, edit the main card, the preset screen and the dashboard.
Introduction: The editor's first page. At the top are the banks/presets row and the PRESET / LIVE
        toggle with the LAYER badge. In the PRESET sub-mode you edit the preset's "business card"
        (name, PC, extras, screen appearance); in the LIVE sub-mode you set the function of each

6.1. Top of the page (header and navigation)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: PRESET PAGE — TOP
Purpose: Select what you're editing and keep track of the connection status.
How to:
1. Tap the bank tile (large letter) to cycle A → B → C → … → J.
2. Tap one of the 6 preset buttons to recall it — the controller switches along, in real time.
3. Use the PRESET / LIVE toggle to switch between editing the preset and editing the footswitches.
Fields and items:
- WiFi icon (header) (status)
  Description: Shows the radio state: gray = offline, yellow = AP mode (the pedal's network), green
             = STA mode (connected to your router). Tap to see details/connect.
- USB icon (header) (status)
  Description: Blue = connected via USB cable (Web Serial). Tap to connect/disconnect. When USB is
             active, all the editor's traffic goes through the cable — independent of WiFi.
- MIDI Monitor (header) (button)
  Description: Opens the MIDI Monitor: a window showing what the current preset sends (snapshot) and
             the last footswitch trigger, with a copy-as-text button — great for debugging what's
             reaching your effects unit.
- Theme (header) (button)
  Description: Toggles the editor's light/dark theme. The display previews stay dark on purpose
             (they represent the pedal's physical screen).
- Bank tile (letter A–J) (button)
  Description: Shows the active bank's letter and the current preset's name right below. Each tap
             advances to the next enabled letter. The dot in the corner indicates the state (orange
             = ok, red = communication error).
- Preset buttons 1–6 (button)
  Description: Select the preset within the bank. The active one gets an orange border and a lit
             LED. Selecting here recalls the preset on the controller (sends the configured MIDI).
- PRESET / LIVE toggle (selection)
  Description: Switches the page content between preset editing (MAIN/DISPLAY/dashboard cards) and
             footswitch editing (LIVE). The sync button mirrors the mode on the physical controller
             too.
- LAYER badge (1/2) (indicator)
  Description: In the center of the toggle, shows which function layer is being edited/displayed.
             Only appears when Layer 2 is enabled (GLOBAL > LEDS > Dedicated).
Examples:
- Trocar de música no ensaio: toque no tile até chegar no banco B, depois toque no preset 3 — o
   pedal já manda o MIDI da música.

6.2. MAIN Card
~~~~~~~~~~~~~~
Related screen/preview: MAIN — A1
Purpose: The heart of the preset: sets the name, the main Program Change, the MIDI channel and the
          extra messages triggered when the preset is recalled.
How to:
1. Give the preset a name (it appears on the pedal's display).
2. Set the main PC and the channel of your destination device.
3. Tap “+” to add extra messages (other PCs/CCs triggered along).
4. Tap SAVE (bottom bar) to store.
Fields and items:
- PRESET NAME (text)
  Description: Up to 16 characters. It's what appears on the controller's display and on the bank
             tile. Empty = shows the tag (e.g.: A1). Don't use the characters |, = and :.
- PC (main Program Change) (number)
  Description: The program sent when recalling the preset. 0–600: values above 127 are automatically
             translated with Bank Select (MSB/LSB), according to the destination device. With
             Friendly Mode active, the sound name appears instead of the number.
- CHANNEL (selection)
  Description: MIDI channel of the main message. MUTE · 1–16. MUTE disables the main message (the
             preset can still send extras and the switches keep working).
- ADD MESSAGE (“+”) (button)
  Description: Up to 4 extra PC messages and 2 extra CC messages, triggered along with the preset —
             to control a second device, change a scene, turn on an effect right away. Each row
             shows channel + number, and can be edited or removed.
- PC ↔ CC type badge (button)
  Description: Each extra message has a badge in the corner with the destination type. Tapping it
             converts the row from PC to CC (or vice versa), preserving channel and number — as long
             as there's a free slot of the destination type.
- Fixed value of CC rows (ON/OFF) (switch)
  Description: Extra CC rows send a fixed value: ON = 127, OFF = 0. Use it to keep an effect always
             on (or off) when entering the preset.
- × to remove (action)
  Description: Each extra row has a × in the channel corner to remove it. When there are PC extras,
             the main row also gets a × — it removes the current main PC and promotes the first
             extra to main (useful when you built the preset "backwards").
- EXP value — expression pedal per preset (special value)
  Description: New in v13. On an extra send of type CC, the VALUE list gained one option at the end:
             EXP (EXPRESSION PEDAL). Choose it and that row sends no MIDI when the preset is called
             — instead it tells the expression pedal where to point while this preset is active.
             In other words: the CC and channel on the global External Expression card become just
             the default. A preset with an EXP row replaces that destination (it doesn't add to it)
             — and it can have several, if you want the same pedal driving different CCs or channels
             at once.
             One practical detail: a preset with an EXP row turns pedal reading on by itself, even
             with the global expression switch off. That's deliberate, for people who use expression
             entirely per preset — but it means configuring this with no pedal plugged in can
             generate CC on its own, from the floating input.
             The option only appears on boards that have an expression input; if the preset already
             has EXP saved, it stays visible regardless.
Examples:
- Dois aparelhos: PC principal 24 no canal 1 (pedaleira) + extra PC 5 no canal 2 (sintetizador) +
   extra CC 7=127 no canal 1 (volume no máximo).
- Modo amigável: com Match Mode configurado para sua pedaleira (GLOBAL > MIDI), em vez de "PC 24"
   você vê o nome real do patch.
Notes:
- Changes only go to the pedal when you tap SAVE — the card's footer shows LOADING / SAVING / SAVED
   / ERROR.
- A channel in MUTE paints the text red as a visual reminder.

6.3. Preset DISPLAY tab (appearance on screen)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: MAIN — DISPLAY TAB
Purpose: Control how the preset appears on the controller's physical screen: colors, background,
          font and free name position.
How to:
1. Open the DISPLAY tab inside the MAIN card.
2. Choose the colors by tapping the color bars (they open a picker with the palette).
3. The preview updates instantly; tap SAVE to store.
Fields and items:
- SIZE (button)
  Description: Font size of the name on the display — each tap cycles the available sizes: 9 · 12 ·
             18 · 24 pt.
- BOLD (button)
  Description: Applies bold weight to the name's font on the display (YES/NO).
- NAME COLOR (color)
  Description: Color of the preset name text on the display. Tap the bar to open the display's own
             palette (different from the LED palette).
- NAME BORDER (color)
  Description: Color of the outline/highlight around the name on the display.
- BACKGROUND (color / image)
  Description: Screen background when the preset is active in BANK/PRESET mode. It can be a solid
             color, gradient or one of the 10 images uploaded in GLOBAL > DISPLAY > Images.
- NAME POSITION (button → drag)
  Description: Position of the name on the display, fully free. Tap the button to open a window with
             a screen preview and drag the name anywhere (mouse or finger). The Center button
             returns to the middle; Apply confirms.
             When PRESET mode uses a layout with icons (GLOBAL > DISPLAY > PRESET layout 1 to 4),
             the preview shows the areas where the icons sit — so you place the name in the empty
             space, without covering the icons.
- TAG COLOR (color)
  Description: Color of the tag indicator (e.g.: A1) shown on the display.
- BACK LAYERS (color / image)
  Description: Screen background behind the tiles in LIVE mode. It also accepts an image from the
             slots.
- SCREEN LAYOUT — now per preset too (selection)
  Description: New in v13. The layout of the PRESET and LIVE screens (arrangements 1–4, LIST and
             CUSTOM) has always been a global setting. Now each preset can have its own — including
             the CUSTOM arrangement's positions.
             It works by inheritance: as long as you choose nothing here, the preset follows the
             global layout — and keeps following it if you change the global later. The moment you
             pick a layout for this preset, it rules that preset alone.
             This is what lets you have one song with four big effects on screen and the next one
             with the preset list, without changing any setting mid-show.
             Presets and backups made before v13 stay exactly as they were: with no choice stored,
             they all inherit the global.
Examples:
- Visual por música: cada preset com uma foto de fundo diferente (capa da música) e o nome
   centralizado em 24 pt negrito.
Notes:
- Images removed from the slots make the background revert to black automatically (no error).
- Background images aren't included in the backup by the old default — use backup v3 with "include
   images and icons" checked.

TOPIC 7 - FOOTSWITCH MODES (LIVE)
----------------------------------------------------------------------------------------
Summary: STOMP, MACROS, MOMENTARY, TAP TEMPO, SPIN, RAMP, SINGLE, STEPS and CONTROL — what each mode
        does and all of its fields.
Introduction: In the LIVE sub-mode of the PRESET page, each footswitch (SW1–SW6) gets an operating
        mode. Select the SW in the button row, choose the mode in the selector and configure it on
        the gear tab (SETTINGS); the DISPLAY tab handles the tile's appearance.
        Two important moments: when the preset is recalled (in any mode) the pedal sends the initial
        MIDI of the switches that have a starting state; in LIVE the switch becomes interactive and
        the LED reflects its state.

7.1. STOMP
~~~~~~~~~~
Related screen/preview: SW1 · STOMP — SETTINGS tab
Purpose: The classic effect on/off (toggle) mode. A single STOMP can have up to 3 sections — each
          triggered by a different foot gesture — and any section can become a FAVORITE shortcut to
          another preset.
How to:
1. Set up section A (single tap). If you want, also enable B (press and hold) and C (double tap).
2. The behavior adapts itself: A only = classic STOMP (hold = momentary); A+B = DUAL; A+B+C = TRIAL.
3. Each section can send CC or PC (SEND CC / SEND PC button), or even be a FAVORITE.
Fields and items:
- Sections (SHORT CLICK / LONG CLICK / RECLICK) (selection)
  Description: The 3 gesture tabs of the section: SHORT CLICK (single tap), LONG CLICK (press and
             hold) and RECLICK (double tap). Each has the same fields below; a section becomes
             active when it gets a channel.
- CC (number) (number)
  Description: The section's Control Change number. 0–127. On Kemper channels, the list also shows
             the named special controls (200–321). Options marked with » are navigation commands
             (see the Advanced features section).
- Channel (selection)
  Description: The section's MIDI channel. OFF · 1–16. OFF disables the section (it doesn't count
             toward the adaptive behavior).
- SEND CC / SEND PC (button)
  Description: Toggles what the section sends: a CC toggle (default) or a Program Change per state —
             one PC for on, another for off (value −1 = doesn't send in that direction). In PC mode,
             the CC and CUSTOM fields disappear.
- CUSTOM (button)
  Description: By default the toggle sends 127 (on) and 0 (off). Enable CUSTOM to set your own ON
             and OFF values 0–127 — useful for switching between two levels of a parameter (e.g. two
             volumes).
- Options (Trigger on preset · Starts ON) (switch)
  Description: Trigger on preset (on by default): when the preset is recalled the pedal already
             sends the CC with the initial state value — your rig stays in sync from the first
             second. Starts ON: the section's initial state (on/off) when the preset is recalled.
- FAVORITO (button)
  Description: Turns the section into a preset shortcut: instead of sending MIDI, the tap loads a
             specific bank/preset. The MIDI fields give way to a bank selector A–J, preset and
             arrival mode (PRESET or LIVE).
- LED (color)
  Description: Tap the arc to choose the section's LED color when on. In DUAL/TRIAL, each section
             lights its own ring pixel in its color.
- SINGLE RING (undivided LED) (switch)
  Description: Normally a STOMP with two or three sections splits the ring's 3 pixels — one colour
             per section. Turning SINGLE RING on lights all three together, in the colour of the
             last section you touched, following that section's on/off.
             It makes the ring mirror what the on-screen tile already does. Useful when what matters
             is seeing from a distance which effect just changed, rather than the state of all three
             at once.
             The option belongs to the whole footswitch (not per gesture): it appears on the
             short-click tab and, once on, already applies to all three gestures.
Examples:
- Drive no toque, solo no segurar: seção A liga o drive (CC 49); seção B (long press) liga o boost
   de solo (CC 50).
- Atalho de emergência: seção C (toque duplo) como FAVORITE para o preset E6 ("limpo geral").
Notes:
- In TRIAL (3 sections), the single tap only triggers after the double-tap window (~350 ms) — that's
   the price of having 3 gestures on one switch.
- FAVORITE sections don't trigger MIDI when the preset is recalled.

7.2. MACROS
~~~~~~~~~~~
Related screen/preview: SW2 · MACROS — SETTINGS tab
Purpose: A toggle that fires up to 4 MIDI messages at once — CC or PC, each with its own ON and OFF
          value.
How to:
1. Add up to 4 slots with ADD SLOT.
2. For each slot choose the type (CC or PC), the channel, the number and the values for ON and OFF.
3. Value OFF (−1) in ON or OFF = that slot sends nothing in that direction.
Fields and items:
- Slot (MIDI message) (group)
  Description: Each slot is an independent message: type (CC or PC), channel CH OFF · 1–16 (OFF
             disables the slot) and the CC/PC number 0–127. All slots fire together when the switch
             toggles.
- SEND CC / SEND PC (badge) (button)
  Description: Tap the badge to switch the slot's message between CC (control, with ON/OFF values)
             and PC (program change, with PC ON/PC OFF).
- ON / OFF (slot values) (number)
  Description: What the slot sends when the switch turns on and when it turns off. 0–127, or OFF
             (−1) to send nothing in that direction. In PC slots, these are the two programs (PC ON
             / PC OFF).
- ADD / REMOVE SLOT (button)
  Description: Adds one more slot (up to 4) or removes the last one.
- Options (Trigger on preset · Starts ON) (switch)
  Description: Trigger on preset: recalling the preset sends the initial-state values of all slots.
             Starts ON: the switch's logical state when the preset is recalled.
- LED (color)
  Description: Tap the arc to choose the switch's color on the LED ring.
Examples:
- Cena completa num toque: seção A liga delay (CC 51=127), reverb (CC 53=127) e sobe o volume (CC
   7=110) de uma vez; ao desligar, manda tudo de volta.

7.3. MOMENTARY
~~~~~~~~~~~~~~
Related screen/preview: SW3 · MOMENTARY — SETTINGS tab
Purpose: Fires a pulse (a value out and then immediately the value back) on each press — with no
          on/off state. Good for functions like "next page", momentary hold, etc.
How to:
1. Set up to 4 slots; all fire together on each press.
2. Each slot sends CC = valor ON, and ~2 ms later CC = valor OFF.
Fields and items:
- Slot (CC + Channel) (group)
  Description: Each slot pulses a Control Change: CC number 0–127 and channel OFF · 1–16 (OFF
             disables the slot).
- ON / OFF (out and back) (number)
  Description: The value sent at the moment of the press (ON) and the value sent immediately after
             to complete the pulse (OFF). 0–127 each.
- PULSE (test) (action)
  Description: Fires the pulse of all slots right away, straight from the editor — to test without
             stepping on the pedal.
- LED (color)
  Description: Tap the arc to choose the color: the LED gives a flash in that color on each press,
             as visual feedback.
- ADD / REMOVE SLOT (button)
  Description: Up to 4 slots; all pulses fire together on each press.
Examples:
- Virar página do tablet: CC 80 com pulso 127→0 no canal do app de partituras.
Notes:
- MOMENTARY only works in LIVE — it sends nothing when the preset is recalled.

7.4. TAP TEMPO
~~~~~~~~~~~~~~
Related screen/preview: SW4 · TAP TEMPO — SETTINGS tab
Purpose: Tap the song's tempo with your foot: each tap sends tap-tempo CCs to up to 3 devices, and
          the LED starts blinking at that tempo. There's also an extra LONG PRESS slot with an
          independent toggle.
How to:
1. Add up to 3 tap slots (channel + CC + send mode).
2. Tap 2+ times to set the tempo — the LED blinks along.
3. Set up the HOLD slot (long press) if you want a second function on the same switch (e.g. turning
   on the tuner).
Fields and items:
- Tap slot (CC + Channel) (group)
  Description: Your device's tap-tempo Control Change (check its manual) and the channel OFF · 1–16.
             On each tap the pedal sends CC = 127 from all slots. Up to 3 slots.
- MODE 1 / MODE 2 (button)
  Description: MODE 1 (classic): sends only CC=127 on each tap. MODE 2 (pulse): sends CC=127
             followed by CC=0 — for devices that require the full pulse.
- HOLD (long press) (group)
  Description: An independent toggle triggered by holding the switch (~300 ms): its own CC + channel
             and ON/OFF values 0–127. E.g.: CC 31 opens/closes the Kemper tuner. Channel OFF
             disables the long press.
- Options (Trigger on preset · Starts ON) (switch)
  Description: They apply to the HOLD toggle: whether the preset load sends the initial-state value,
             and what that state is (on/off). The tap slots never fire on load.
- LED (color)
  Description: Blink color. With no tempo tapped, the pixels circle slowly; with a tempo, the 3
             pixels blink at the song's tempo.
- ADD TAP / REMOVE (button)
  Description: Adds one more tap slot (up to 3) or removes the last one.
Examples:
- Delay no tempo da música: slot 1 com o CC de tap do seu delay; segure o mesmo switch para
   ligar/desligar o afinador (CC 31 no Kemper).
Notes:
- The tap is counted when you release your foot (not when you press), so that holding doesn't count
   as a tap.
- The tap slots fire nothing when the preset is recalled; only the HOLD slot can fire (if
   configured).

7.5. SPIN
~~~~~~~~~
Related screen/preview: SW5 · SPIN — SETTINGS tab
Purpose: A cycle of 3 states: each tap advances 1 → 2 → 3 → 1, sending a different value of up to 3
          simultaneous CCs for each state. The LED shows which state is active.
How to:
1. Set up to 3 slots of CC; each slot has three values (1, 2, 3) — one per state.
2. Each foot tap advances the state and sends the corresponding value of all slots.
3. The editor's range fader helps set the three values visually.
4. There's also a HOLD slot (long press) with an independent toggle, just like in TAP TEMPO.
Fields and items:
- SLOT 1 / 2 / 3 tabs (selection)
  Description: Up to 3 CC slots, all fired simultaneously on each state of the cycle. The dot •
             marks slots with a configured channel; tap a tab to edit that slot.
- MIDI message (CC + Channel) (group)
  Description: The Control Change cycled by the active slot 0–127 and the channel OFF · 1–16.
- 3-state cycle (PX 1 → 2 → 3) (fader)
  Description: The three values sent in states 1, 2 and 3 — each row has a selector and a fader with
             the percentage beside it. Tapping PX n previews that state on the LED (without sending
             MIDI).
- TRIGGER ON PRESET / WAIT FOR LIVE MODE (button)
  Description: On: the preset enters state 1 directly (sends value 1 of all slots). Off: the switch
             stays "waiting" (pixel 1 blinking) until the first tap.
- LED (active pixel color) (color)
  Description: Each press cycles PX 1 → 2 → 3 and the corresponding arc pixel lights in this color.
- HOLD (long press) (group)
  Description: Independent toggle triggered by holding (~300 ms): its own CC, channel and ON/OFF
             values, with its own color — when ON, the 2 pixels SPIN isn't using light up in it. The
             cycle advances when you release your foot, so holding doesn't skip a state.
Examples:
- Três níveis de gain: CC 4 com v1=30 (clean), v2=70 (crunch), v3=120 (lead) — um toque por nível.

7.6. RAMPA
~~~~~~~~~~
Related screen/preview: SW6 · RAMP — SETTINGS tab
Purpose: Sweeps a CC's value gradually between a minimum and a maximum — like an automatic
          expression pedal with configurable curve and timing.
How to:
1. Set the CC, the channel and the minimum / maximum values.
2. Choose the rise and fall time, the curve and the trigger type.
3. In LIVE, press the switch to start the sweep — the LED brightness follows the value.
Fields and items:
- CC / Channel (selection)
  Description: The Control Change swept by the ramp 0–127 and the destination channel OFF · 1–16.
- MIN / MAX (number)
  Description: The two extremes of the sweep. 0–127 each.
- RISE / FALL (ms) (fader)
  Description: Duration of each direction of the sweep — numeric field + fader. 100–3000 ms.
- CURVE (LINEAR / EXP / LOG / SINE) (selection)
  Description: Shape of the sweep: LINEAR (constant), EXP (starts slow, speeds up), LOG (starts
             fast, slows down), SINE (smooth at the ends).
- TOGGLE / HOLD / LOOP (selection)
  Description: The trigger: TOGGLE — each tap reverses the direction (halfway, it reverses
             proportionally); HOLD — rises while held, falls on release; LOOP — one tap starts a
             continuous back-and-forth, another tap stops it.
- SWEEP (test) (action)
  Description: Tests the ramp straight from the editor: sends the two extremes and blinks the LED
             (the real continuous sweep happens on the pedal).
- LED (color)
  Description: Tap the arc to choose the color. On the pedal, the brightness follows the current
             value of the sweep.
Examples:
- Swell de volume: CC 7, mín 0 → máx 127, subida 2000 ms, curva SINE, gatilho HOLD — segure para o
   som "nascer".
- Filtro psicodélico: CC 74 em LOOP de 4 s com curva SINE.
Notes:
- RAMP only operates in LIVE — it never sends anything when the preset is recalled (by design).

7.7. SINGLE
~~~~~~~~~~~
Related screen/preview: SW1 · SINGLE — SETTINGS tab
Purpose: Fires a single burst of messages (with no on/off): up to 4 CC or PC slots on each tap. Now
          with three independent gestures on the same footswitch — a short TAP, LONG PRESS (hold)
          and RECLICK (double tap) —, each with its own slots and LED color. When several switches
          are in SINGLE, only the last one tapped stays lit (in that gesture's color) — a
          "selection" behavior.
How to:
1. On the short TAP gesture (1 tap), add up to 4 slots; choose CC or PC, channel, number and value.
2. Each tap fires all the slots of that gesture.
3. Optional: fill in LONG PRESS (hold) and/or RECLICK (double tap) to get up to 3 different triggers
   on the same footswitch.
Fields and items:
- Slot (MIDI message) (group)
  Description: Each slot fires a message: channel CH OFF · 1–16 (OFF disables the slot) and the CC
             number 0–127 or PC number 0–16383.
- SEND CC / SEND PC (badge) (button)
  Description: Tap the badge to switch between CC (control with value) and PC (program change —
             becomes a numeric program field).
- Value (CC slots) (number)
  Description: The value sent along with the CC. 0–127. PC slots don't have this field (the program
             number is the send itself).
- ADD / REMOVE SLOT (button)
  Description: Up to 4 slots; all fire together on each tap.
- Options (Trigger on preset) (switch)
  Description: If on (default), the slots also fire when the preset is recalled.
- LED (color)
  Description: LED color of the short TAP gesture when this is the last SINGLE tapped. The other
             SINGLE switches turn off (a "selection" behavior).
- LONG PRESS (hold · ~300 ms) (group)
  Description: Holding the footswitch for ~300 ms fires another up to 4 slots (CC/PC), with its own
             LED color. Once LONG is set, the short TAP now fires when you release the footswitch,
             to tell the two gestures apart. Leave the channel OFF to disable it.
- RECLICK (double tap · 2 taps) (group)
  Description: Two quick taps (a ~350 ms window) fire another up to 4 slots, also with its own LED
             color. With RECLICK set, the short TAP waits for the double-tap window to close before
             acting. Channel OFF disables it.
Examples:
- Snapshots/cenas: SW1–SW4 em SINGLE, cada um mandando o PC de uma cena — o LED aceso mostra a cena
   ativa.
- 3 funções num pé só: toque CURTO chama a cena A, SEGURAR abre o afinador (CC 31), TOQUE DUPLO
   manda mute — cada gesto com sua cor de LED.
Notes:
- LONG PRESS and RECLICK exist only on the pedal's 6 footswitches. On SW GLOBAL and the external
   switches, SINGLE uses only the short tap.
- On the display, the switch tile shows the icon of the last gesture fired and the ring lights in
   that gesture's color.

7.8. STEPS — CC sequencer
~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SW — STEPS MODE
Purpose: When on, the footswitch keeps sweeping four values on a single CC, looping by itself —
          until you turn it off. It does what you'd otherwise do by turning a knob in time with the
          music: a filter opening and closing, tremolo, a delay changing time.
How to:
1. Choose the steps CC and the channel — that's the parameter being swept.
2. Fill in the four values of the sequence (0–127 each).
3. Choose the timing: MANUAL (a time in milliseconds per step) or TAP SYNC (each step with its own
   musical figure over the beat).
4. Optionally turn on the effect: a second CC that gets ON when the sequence starts and OFF when it
   stops. Leaving its channel OFF makes the mode a pure sequencer.
Fields and items:
- The four values (sequence)
  Description: The sequence the CC will run through, in order, forever: 0 → 40 → 90 → 127 → 0 → ….
             All between 0 and 127.
             When you switch it on, the first step goes out immediately — the interval only applies
             between one step and the next. When you switch it off, it stops right there, without
             finishing the cycle. And restarting always begins at Step 1.
- MANUAL — a time per step (timing)
  Description: Each step has its own time in milliseconds, from 20 ms to 60 s. Since all four are
             independent, you can build uneven rhythms — three short and one long, for instance.
- TAP SYNC — in time with the music (timing)
  Description: Instead of milliseconds, each step gets a musical figure (quarter, eighth, triplet…)
             measured against the beat. Tapped a new tempo on TAP TEMPO? The sequence already
             playing changes with it.
             The beat can come from the TAP (the tempo you tap with your foot) or be MANUAL — a
             typed BPM, 20 to 300. With a manual beat this switch ignores the tap on purpose: that's
             what lets you keep a fixed rhythm in the preset while another footswitch taps a delay's
             tempo.
- Effect CC (optional) (send)
  Description: A second CC, with its own channel, that receives ON when the sequence starts and OFF
             when it stops — usually to switch on the effect the sequence is modulating.
             The channel is what enables it: leave it OFF and nothing is sent, turning the mode into
             a pure sequencer. There's no separate switch.
- LED and tile (visual)
  Description: The ring lights up in the chosen colour while the sequence runs, and the current
             step's pixel blinks — so you can see the tempo without looking at the effects unit. On
             very fast sequences the blink is suppressed (you couldn't see it, and it would be
             expensive).
Notes:
- STEPS only works in LIVE mode and doesn't fire when the preset is called — like RAMP. Calling
   another preset stops the sequence.
- Navigation commands (change bank/preset) are refused on the steps CC: in a half-second loop they
   would change banks twice per second.
- Available on footswitches SW1–SW6. Not yet on the Global SWs or the external switches.

7.9. CONTROL — A/B selector (FX 1 / FX 2)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SW — CONTROL MODE
Purpose: One click alternating two destinations: the one coming in gets 127, the one going out gets
          0. They're never both on nor both off — it's an A/B selector, not a pair of independent
          pedals.
How to:
1. Choose the CC and channel for FX 1 in the first tab.
2. Switch to the FX 2 tab and do the same for the second destination.
3. Choose each one's ring colour — that's what tells you on stage which is active.
4. Set which of the two starts active when the preset is called.
Fields and items:
- FX 1 / FX 2 (tabs)
  Description: The two destinations, each with its own CC, channel and colour. One tap moves from
             one to the other: the one coming in gets 127, the one going out gets 0.
             The values are fixed on purpose — there are no custom value fields. If you need other
             values, use STOMP.
- When to use CONTROL instead of STOMP (concept)
  Description: Use CONTROL when the two effects are alternatives: two amps, two channels, two
             cabinets — cases where having both on makes no sense.
             Use a two-section STOMP when they're independent: a drive and a delay that can be on
             together, off together, or just one. In STOMP they also live on different gestures
             (short and long); here they share the same click.
- Ring colour per destination (visual)
  Description: Each destination has its own colour, and the ring shows which one is active now.
             Since there's no "off" state, the ring never goes dark — it changes colour.
             The name (the label) on screen also has its own colour per destination, and the icon
             can differ between them.
- Starting destination (selection)
  Description: Which of the two is active when the preset is called. With send-on-call enabled (the
             default), the 127/0 pair goes out together with the preset — so the device wakes up on
             the right destination without you stepping on anything.
- A destination with channel OFF (detail)
  Description: A destination with no channel is skipped when sending, but still exists: the switch
             keeps alternating and the visuals keep changing. That's how you use CONTROL with a
             single destination and still get two visual states on the tile and ring.
Notes:
- The 0 of the outgoing destination goes first. On devices where both effects share the same block,
   sending the 127 first would leave both on for an instant — and some resolve that by turning both
   off.
- Available on footswitches SW1–SW6. Not yet on the Global SWs or the external switches.

7.10. MUTE (default)
~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SW1 · MUTE — SETTINGS tab
Purpose: The default state of a switch with no function: it sends nothing and doesn't light the LED.
          Use it to "turn off" a switch in a preset.
Notes:
- Changing a switch's mode doesn't erase the previous mode's parameters — if you go back to the old
   mode, the settings reappear.

7.11. Switch DISPLAY tab (tile appearance)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SW1 · STOMP — DISPLAY tab
Purpose: Configure how each footswitch appears on the display in LIVE: icon or abbreviation, tile
          colors and variations per sub-state.
How to:
1. With the SW selected, open the DISPLAY tab.
2. Choose an icon (internal catalog, colored icons or PNGs uploaded by you) or a text/abbreviation.
3. Adjust the icon, background and border colors for the on/off states.
4. Modes with sub-states (SPIN with 3, STOMP with sections, TAP) have their own editor per
   sub-state.
Fields and items:
- ICON / BACKGROUND / BORDER colors (OFF — ON) (color)
  Description: Each row defines the color of a tile element in the two states: OFF (off) and ON
             (on). Default: red icon on / gray off, transparent background, border following the
             icon. Colored icons (ready-made images) don't show the ICON row — only background and
             border.
- Tile preview (tap to change the icon) (gallery)
  Description: Shows exactly how the tile will look on the physical display. Tapping it opens the
             icon selector: tinted (drawings that accept color), colored (ready-made images, e.g.
             pedal thumbnails), uploaded PNGs (upload slots in GLOBAL > SCREEN) or just
             text/abbreviation.
- PREVIEW ON / PREVIEW OFF (button)
  Description: Toggles the state shown in the preview — to check the on and off colors without
             leaving the editor.
- ICON NAME / ABBREVIATION (text)
  Description: Short text (up to 8 characters) shown on the tile — it becomes the main content when
             the "text" mode is chosen in the selector.
- NAME COLOR (color)
  Description: A dedicated color for the name/abbreviation, next to the text field. The name used to
             inherit the icon color; now it is separate — essential with colored or uploaded PNG
             icons, which have no editable icon color. Keep it following the icon (default) or pick
             a color just for the text.
- NAME FONT SIZE (selection)
  Description: New in v13: the size the pedal uses to write the footswitch's label is no longer
             automatic-only. The options are AUTO (the usual calculation, which adapts to the tile
             height) and four fixed sizes — 9, 12, 18 and 24 pt.
             An explicit choice overrides the reduced size of small-tile layouts: if you asked for
             24 pt, 24 pt is what you get. But if the text doesn't fit the box, the pedal steps down
             one notch at a time (24 → 18 → 12 → 9) until it does — choosing the size is yours,
             overflowing the tile isn't, and a clipped label on stage reads as a fault.
             The size belongs to the whole footswitch, not to a state or a gesture: the tile has a
             single name, and a size per state would make the text jump on every tap. That's why the
             same row appears in all four display editors.
Examples:
- Tile de drive: ícone de pedal, fundo transparente, ícone vermelho quando ligado / cinza quando
   desligado.
Notes:
- Presets saved in older versions may need a re-edit to record all sub-states.

TOPIC 8 - GLOBAL PAGE
----------------------------------------------------------------------------------------
Summary: Settings that apply to all presets: MIDI, controls, display, LEDs, banks, preset call and
        combos.
Introduction: The GLOBAL page has 5 tabs: MIDI · CONTROLS · DISPLAY · LEDS · BANKS. Everything here
        applies to the entire controller (not per preset) and is stored in protected memory — it
        survives even reinstalling the editor.
Tabs on this page: MIDI · CONTROLS · DISPLAY · LEDS · BANKS

8.1. Friendly Mode (Match Mode)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › MIDI — FRIENDLY MODE
Purpose: Map each MIDI channel to a known pedal/device, so the editor shows real PC and CC names
          ("Booster", "Delay On") instead of raw numbers.
How to:
1. Choose a single pedal for the entire controller, or enable MULTIPLE MODE to choose one pedal per
   channel (1–16).
2. After that, all the editor's PC/CC selectors show that device's names on the corresponding
   channel.
Fields and items:
- PC/CC mapping target (selection)
  Description: The target device. The list covers popular effects units (Ampero, HX Stomp, Kemper,
             Quad Cortex…) — choosing KEMPER PLAYER also enables the Kemper card. The first option,
             MULTIPLE MODE — per channel, swaps the single pedal for the channel grid below.
- Per-channel grid (CH 1–16) (selection)
  Description: In MULTIPLE MODE, each tile maps one pedal per MIDI channel — for rigs with several
             devices. The editor's PC/CC selectors then show the names of that channel's device. "—"
             = channel with no mapping. There are 16 channels across 3 pages of 6 (CH 1–6, 7–12,
             13–16) — tap the tabs to switch.
- CC on LIVE (per channel) (number)
  Description: A CC fired automatically when entering LIVE (value 127) and when leaving (value 0),
             per channel. For pedals that have a "scene/stomp mode" and should follow the
             controller's screen. Works even with no pedal mapped to the channel.
- Omit unnamed PC/CC (switch)
  Description: Hides from the selectors the PC/CC numbers that have no name on the chosen device —
             the list keeps only what really exists.

8.2. Kemper Player
~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › MIDI — KEMPER PLAYER
Purpose: Exclusive features for those using the Kemper Profiler Player plugged in via USB: rig name
          on the display, synchronized preset change and a tuner on the pedal's screen.
How to:
1. Available when Match Mode points to KEMPER PLAYER (single mode or on some channel).
2. Connect the Kemper to the controller's USB (or the controller to the Kemper's USB host).
Fields and items:
- GET NAMES (switch)
  Description: Fetches the Kemper's current rig name via SysEx and shows it on the controller's
             display (BANK and LIVE screens), updating on each change. Lightweight — it only queries
             on a preset change.
- FOLLOW THE KEMPER (switch)
  Description: When you change the rig on the Kemper itself, the controller finds and recalls the
             matching preset (same bank/PC) — a full recall, including the switch state. It works
             through a bidirectional session kept with the Kemper.
- TUNER SCREEN (ARC / BAR / LEDS) (selection)
  Description: The tuner's look on the pedal's screen: ARC (arc needle), BAR (horizontal bar) or
             LEDS (headstock-tuner style). The tuner opens when a switch sends CC 31 = 127 and
             closes with CC 31 = 0. Pressing any other footswitch also closes the tuner — the screen
             returns to normal and the switch runs its own function (change preset, toggle effect,
             etc.).
- DATA ACQUISITION (control)
  Description: How much of what the Kemper sends is shown (decimation of the readings): Smooth = 1
             in every 10 (steadier reading) up to Fast = all of them (immediate response, but more
             jittery).
Notes:
- The Kemper's special controls (◆ list) only appear on channels mapped to KEMPER PLAYER.
- For value CCs with musical meaning (e.g. Transpose), the editor shows friendly labels (semitones,
   rhythmic figures) instead of 0–127.

8.3. Global SW 1 and 2
~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › MIDI — SW GLOBAL
Purpose: Extra footswitches, outside the presets: the function configured here always applies, in
          any bank/preset/mode. There are two — GLOBAL SW 1 and GLOBAL SW 2 —, each with its own
          configuration. Available on boards with the dedicated pin, on models with "SW6 = SW
          Global" enabled, or by retiring the LIVE button (see the last field).
How to:
1. Choose the mode of the global switch (the same modes as the normal switches: STOMP, MACROS, TAP
   TEMPO…).
2. Configure the parameters as on a regular switch.
3. The global switch's dedicated LED reflects the function's state.
Fields and items:
- MODE field (selection)
  Description: Tap to open the mode selector — the switch's permanent function: any available mode
             (STOMP, MACROS, TAP TEMPO…). The editor for the chosen mode appears right below, inside
             the card itself.
- Mode editor (e.g. STOMP) (group)
  Description: The same fields as the normal switch editor — in STOMP: SHORT CLICK/LONG/RECLICK
             gestures, CC + Channel, SEND CC/PC, CUSTOM, FAVORITE and LED. The difference: the SW
             Global never fires when recalling a preset (there is no "Fire on preset" — only "Starts
             ON", the initial state) — it responds only to the foot, in any bank/preset/mode.
- GLOBAL SW 2 (the LIVE button becoming a second global) (switch)
  Description: On boards with a dedicated LIVE button, you can retire it from that job and turn it
             into a second GLOBAL SW, fully independent of the first — with its own mode, its own
             commands and its own look.
             The trade is worth it when you already have another way in and out of LIVE mode (a
             footswitch with SW_LIVE, or a combo). Then the button, which would otherwise sit idle,
             becomes one more always-available pedal.
             The option is in SYSTEM › DEVICE and restarts the controller when changed, because the
             pin changes owner at boot. Both buttons' settings (mode, commands, display) live right
             here, in GLOBAL › CONTROLS.
Notes:
- On the NANO, first enable "SW6 = SW Global" in SYSTEM > MAIN (the controller restarts). SW6 stops
   selecting preset 6.

8.4. External Expression (expression pedal)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › MIDI — EXTERNAL EXPRESSION
Purpose: Connect an analog expression pedal to the EXP input and turn it into a continuous CC
          (0–127).
How to:
1. Enable the feature and choose the target CC and channel.
2. Do the calibration: press to the minimum, save MIN; press to the maximum, save MAX. If the pedal
   is inverted, the calibration corrects it by itself.
Fields and items:
- Enable expression pedal (switch)
  Description: Turns on the expression pedal reading. When off, the EXP pin stays inactive (no
             reading and no MIDI).
- LIVE READING (status)
  Description: The pedal's current MIDI value (0–127) in real time, with the progress bar below —
             move the pedal and watch the response. Handy for checking the calibration before
             saving.
- CC · CHANNEL · CALIBRATION (summary) (action)
  Description: Summary pill of the current configuration. Tap EDIT › to expand the fields below;
             CLOSE › collapses them.
- CC / CHANNEL (number)
  Description: Where the pedal's movement goes: CC number 0–127 and channel 1–16. Classics: CC 7
             (volume), CC 4 (wah), CC 11 (expression). With Match Mode, the CCs appear with names.
- CALIBRATION (MIN / MAX) (action)
  Description: Press to the minimum and tap MIN (0); press to the maximum and tap MAX (127) — it
             records the extreme positions to use the full travel. The numeric fields allow fine ADC
             tuning, and RESET CALIBRATION returns to default. Pedal "backwards"? The calibration
             inverts automatically.
Notes:
- This card only appears on models with an EXP input ("+" variants).

8.5. External Dual Switch
~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › MIDI — EXTERNAL DUAL SWITCH
Purpose: Connect an external dual pedal (2 simple footswitches, no LED) to the BFMIDI-3 (+) boards
          and give each button a function — now with every switch mode and an on-screen state
          indicator that replaces the LED ring they don't have.
How to:
1. Configure each of the two external switches individually, like a mini switch editor.
2. Available modes: STOMP, MACROS, MOMENTARY, TAP TEMPO, SPIN, RAMP and SINGLE — plus the special
   navigation commands. It always fires on press (in BANK or LIVE), never on preset recall.
3. Since they have no LED, turn on the on-screen indicator: pick the scope (LIVE/PRESET/both), the
   label, the ON/OFF colors, the size and the position.
Fields and items:
- External SW1 (group)
  Description: The first external switch: pick the mode (STOMP, MACROS, MOMENTARY, TAP TEMPO, SPIN,
             RAMP or SINGLE) and set the fields below, like a mini SW Global. It fires only on press
             — never on preset load. Special navigation commands also work.
- External SW2 (group)
  Description: The second external switch — independent of the first, same options and same modes.
- RESET ON PRESET RECALL (switch)
  Description: When on, recalling a preset returns the external switch's indicator to OFF — without
             sending MIDI. Handy so each preset starts from a "clean" state.
- ON-SCREEN INDICATOR (scope) (selector)
  Description: Turns on the switch's on-screen state box (it has no LED). Scope: OFF (hidden), LIVE,
             PRESET or BOTH. Only on the big-screen BFMIDI-3 (+) models (non-MICRO).
- LABEL · COLORS · SIZE (group)
  Description: Label (up to 5 letters, e.g. ESW1), the box's ON color and OFF color, and the font
             size. The ON color shows when the switch is on; the OFF color when off.
- ON-SCREEN POSITION (action)
  Description: Open the position editor and drag the box wherever you want over the screen layout
             (X/Y). Each external switch has its own.
Notes:
- The external switches have no LED — use the on-screen indicator for visual feedback of the state.
- In SINGLE mode, the external switch gains the START ON (initial visual state) and REMEMBER STATE
   (toggles the ON/OFF indicator on each tap, without changing the MIDI) options. LONG PRESS and
   RECLICK don't apply here.

8.6. Gig View & screen layouts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › DISPLAY — GIG VIEW & LAYOUTS
Purpose: Define the look of the pedal's screen: stage view, preset name display and the tile
          arrangements — with independent layouts for the LIVE and PRESET modes (including the
          names-based LIST layout) and the icon shape (including octagon).
How to:
1. Enable Gig View to prioritize legibility on stage.
2. Choose the LIVE mode layout and, separately, the PRESET mode layout — each with its own icon
   shape.
Fields and items:
- Gig View (DEFAULT / PRESET ONLY / LIVE ONLY) (selection)
  Description: DEFAULT: the display follows the real mode (BANK or LIVE). PRESET ONLY / LIVE ONLY:
             locks the screen to a single format, regardless of the mode — a simplified stage view.
- Show preset name in LIVE (switch)
  Description: Shows (or hides) the band with the preset name on the LIVE screen. With the Kemper +
             GET NAMES, the band shows the rig name.
- Show preset name in BANK (switch)
  Description: The same, for the BANK screen.
- LIVE mode layout (L1–L4) + shape (selection)
  Description: Four tile arrangements on the LIVE display — each button shows a mini-preview (tiles
             + name band). Automatically adapted on 4-switch boards.
- ICON SHAPE (DEFAULT / CIRCLE / OCTAGON) (selection)
  Description: Tile shape: rounded corners (DEFAULT), circle or octagon. It's independent per mode —
             LIVE and PRESET each have their own. The layouts' mini-previews reflect the choice.
- PRESET mode layout (NONE / L1–L4 / LIST) (selection)
  Description: Screen arrangement in BANK/PRESET mode, independent of LIVE. NONE = classic screen
             (just the preset name, as it has always been); L1–L4 show the switch icons — it can
             differ from the layout chosen in LIVE. It has its own icon shape.
             LIST = the current preset name centered, bigger and framed, with the next presets above
             and the previous ones below (3 on each side) — like a scrolling setlist. The order
             follows the 60 presets (A1…J6), wraps around at the ends and skips banks disabled in
             PRESET LEVELS. The list uses the current preset's font and colors; with the Kemper +
             GET NAMES, the center shows the rig name.

8.7. Images & Icons (media)
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › DISPLAY — IMAGES & ICONS
Purpose: Upload your own background images (JPEG) and icons (PNG) to use in presets and tiles.
How to:
1. Open Images or Icons in the media card.
2. Choose a slot, upload the file and adjust it in the mini-editor.
3. Use the image as a background in the preset's DISPLAY tab; the icon appears in the switch's icon
   picker.
Fields and items:
- BANK background (images) (gallery)
  Description: Opens the background images upload card: 10 JPEG slots, with a usage counter on the
             tile. Limits: 50 KB per file and ~400 KB total. Before uploading, a mini-editor lets
             you drag/zoom to frame, adjust brightness and add up to 5 text boxes with 8 fonts (the
             text is "baked" into the image). Use the image as a background in the preset's DISPLAY
             tab; deleting a slot drops the presets that used it to a black background.
- SW icons (PNG) (gallery)
  Description: Opens the custom icons upload card: 100×100 PNG slots that appear in the switch's
             icon picker alongside the internal catalog. The mini-editor adjusts the framing by
             dragging and the mouse wheel (or gestures on the phone).
Notes:
- Upload works over WiFi and also over USB (chunked transfer — a little slower).
- Track the space in SYSTEM > BACKUP > storage card.

8.8. LEDs (brightness, colors and dedicated)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › LEDS
Purpose: Control the LED ring: overall brightness, color per bank or per switch, preview and the
          dedicated LEDs.
How to:
1. Adjust the brightness on the slider.
2. Choose whether the LED color follows the bank (one color per letter A–J) or the switch (one color
   per position 1–6), by tapping each item's arc.
Fields and items:
- LED brightness (slider)
  Description: Overall ring brightness (PWM). 0–100%. Applied instantly, even before saving.
- BY LETTER / BY SWITCH (selection)
  Description: Where the presets' LED color comes from: BY LETTER = one color per bank A–J (you know
             which bank you're on by the color); BY SWITCH = each position 1–6 has a fixed color,
             regardless of the bank.
- Color arcs (BANK A–J / PRESET 1–6) (color)
  Description: Tap an arc to open the color picker for that item. The grid switches between the 10
             letters or the 6 switches according to the mode chosen above.
- Preview of the off SW (switch)
  Description: In LIVE, the off switch shows a dimmed preview of its color (a lit arc) instead of
             going fully dark — you can see where each function is before stepping on it.
- Preview brightness (slider)
  Description: Shows up when Preview of the off SW is on. Controls the intensity of the lit pixel in
             that preview 0–100%: lower it so the off switch stays very faint (a subtle hint) or
             raise it to full color. It does not affect the brightness of the on switch.
- LIVE MODE LED (color)
  Description: Color of the dedicated LED that indicates the controller is in LIVE mode.
- LAYER 2 LED (color)
  Description: Color that indicates layer 2 is active.
- Enable Layer 2 (switch)
  Description: Turns on the second-layer-of-functions-per-switch feature (see Basic concepts). With
             it off, the LIVE button only enters/exits LIVE.

8.9. Banks (auto-start and activation)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › BANKS
Purpose: Define how the controller powers on and how it navigates between banks.
How to:
1. Set up the auto-start so the pedal powers on already at the first song's preset.
2. Disable the letters you don't use in Active Banks — navigation skips straight past them.
Fields and items:
- Start with preset (switch)
  Description: If on, when the controller is powered up it automatically recalls a preset (sending
             all of its MIDI). When off, the controls below are inactive.
- BANK / LIVE (initial mode) (selection)
  Description: Which mode the controller wakes up in: navigating presets (BANK) or straight into
             performance (LIVE).
- BANK + PRESET (boot target) (selection)
  Description: Which preset is recalled at boot (e.g. A1). Tapping each button cycles the letter and
             the number — letters disabled in Active Banks are skipped.
- Preset Call (its own card)
  Description: The old MODE 1 · HYBRID and MODE 2 · SINGLE are gone. In their place you build
             whatever behaviour you want, footswitch by footswitch and gesture by gesture — see the
             Preset Call card just below.
- Active Banks (chips A–J) (multiple selection)
  Description: Enables/disables each letter. Disabled letters are skipped in navigation — fewer
             clicks if you only use 2 or 3 banks.

8.10. Preset Call (per switch and gesture)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › BANKS — PRESET CALL
Purpose: Decide what each footswitch does in BANK mode — one by one, and for each gesture. This is
          where you build your controller's navigation: call the preset instantly, browse banks
          without changing the sound, move preset up and down, enter LIVE mode.
How to:
1. Choose the gesture tab: SHORT CLICK (fires when you lift your foot) or LONG CLICK (fires after
   about 0.3 s of pressure).
2. For each footswitch (SW1–SW6), pick the action from the list. That's 12 combinations in total — 6
   switches × 2 gestures — and each one is independent of the others.
3. At least one combination must be CALL PRESET or STANDBY — otherwise there would be no way left to
   call a preset with your foot. If you try to leave them all empty, the editor puts CALL PRESET
   back on SW1's short click.
4. Tap SAVE. It applies immediately, no restart needed.
Fields and items:
- SHORT CLICK / LONG CLICK (gesture tabs)
  Description: Two tabs, the same six footswitches in each. The short one fires when you lift your
             foot; the long one, after about 0.3 s held down.
             Why is there no double-click here? Because a double-click only resolves after the
             waiting window (~0.35 s) — and that wait would delay precisely what has to be instant:
             calling the preset.
- CALL PRESET (action)
  Description: Calls that footswitch's preset right away — the classic behaviour. If a preview is
             open (see STANDBY), this is the gesture that confirms the previewed preset.
- STANDBY (action)
  Description: Opens the preview: the display shows the target preset without changing the sound.
             You browse freely and only confirm with a CALL PRESET gesture. It's exactly what the
             old MODE 1 · HYBRID did — except now you choose which switches and which gesture it
             lives on.
- BANK UP / BANK DOWN (action)
  Description: Moves one letter up or down (A → B → C…), calling the preset of the new bank. Letters
             turned off in Active Banks are skipped.
- BANK UP (STANDBY) / BANK DOWN (STANDBY) (action)
  Description: Same as above, but without changing the sound: it moves the letter in preview and
             waits for you to choose the preset. This is the right pair for finding the next song in
             the middle of the previous one.
- PRESET UP / PRESET DOWN (action)
  Description: Steps from one preset to the next inside the bank, cycling around. On 4-footswitch
             boards the cycle is 4 presets long — slots 5 and 6 still exist in the editor, they just
             aren't reachable by foot.
- ENTER LIVE MODE (action)
  Description: Takes you into the current preset's LIVE mode. Useful on boards without a dedicated
             LIVE button (NANO, MICRO, 6SW+) — but remember to leave a way back too: a SW with EXIT
             TO BANK inside LIVE, or a combo with SW_LIVE.
- NONE (action)
  Description: That gesture does nothing on that switch. Leaving a whole footswitch on NONE is
             perfectly fine — what's not allowed is none of the six having a way to call a preset.
Notes:
- Coming from v12? Nothing is lost: the old bank-change mode (HYBRID / SINGLE / LONG) is converted
   automatically into the equivalent gesture pair on all six switches. You only notice the
   difference when you decide to change it.
- Applies to all 6 footswitches in BANK mode. On boards with hybrid switch mode on, it applies only
   to the half that calls presets.
- One switch can have both gestures in use: for example, short = CALL PRESET and long = BANK UP
   (STANDBY). That's how you gain navigation without spending a footswitch.

8.11. Footswitch Combos (two at once)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: GLOBAL › BANKS — FOOTSWITCH COMBOS
Purpose: Pressing two footswitches together fires an action. They used to be two fixed factory
          shortcuts; now there are nine free pairs, and you choose what each one does.
How to:
1. Choose one of the nine pairs available and, in the list beside it, the action it should fire.
2. Leave the pairs you don't want on NONE — a pair with no action simply doesn't exist for the
   pedal.
3. Tap SAVE.
Fields and items:
- The nine pairs (fixed list)
  Description: The possible pairs are SW1+SW2, SW1+SW3, SW2+SW3, SW2+SW4, SW2+SW5, SW3+SW4, SW3+SW6,
             SW4+SW5 and SW5+SW6 — neighbouring combinations your foot can reach without gymnastics.
             On a 4-footswitch board, pairs mentioning SW5 or SW6 simply don't show up.
- Combo action (selection)
  Description: The same list as Preset Call, plus WI-FI ON/OFF and SW_LIVE. Each pair has one
             action.
- WI-FI ON/OFF (action)
  Description: Turns the radio and the web editor on and off instantly. This is the shortcut for the
             most common case: WiFi turned itself off after 90 s idle and you want to open the
             editor without restarting the pedal.
- SW_LIVE (action)
  Description: Enters and exits LIVE mode (it's a toggle). This is the only action that also works
             inside LIVE — and that's exactly why it exists: on boards without a dedicated LIVE
             button it would be the only way back by foot.
- No “hold”, and BANK mode only (rule)
  Description: A combo has one gesture only: the action fires the moment the second foot lands,
             without waiting for you to lift it and with no “held” variant.
             And combos are a BANK mode feature: in LIVE each footswitch keeps the job the preset
             gave it (a combo would steal both). The only exception is the SW_LIVE combo described
             above.
- The long click gets a little slower (side effect)
  Description: A footswitch taking part in an active combo gets a slightly longer long-click (about
             0.45 s instead of 0.3 s). That's deliberate: without that slack, forming a distant pair
             — SW2+SW5, say — would fire the individual long gesture before the combo formed, with
             the MIDI already sent and no undo.
Notes:
- No combo comes configured from the factory. The pairs only start to exist once you pick an action
   here — including the old SW2+SW3 WiFi one.
- If you updated from an earlier version, the two formerly fixed combos are seeded automatically:
   SW2+SW3 = Wi-Fi and, on boards without a dedicated LIVE button, SW1+partner = enter LIVE mode
   (SW2 on NANO and 6SW+, SW3 on MICRO).
- If you press three switches that share pairs (SW2+SW3+SW4, for instance), the pair that closed
   last wins — and it holds priority until you lift both feet.

TOPIC 9 - SYSTEM PAGE
----------------------------------------------------------------------------------------
Summary: Board model, storage, connections, editor preferences, update and backup.
Introduction: The SYSTEM page has 4 tabs: DEVICE · CONNECTIONS · EDITOR · MAINTENANCE. This is where
        the "machine" settings live: hardware model and storage, network and USB Host module, the
        editor's own preferences and data maintenance (update, backup and tests).
        New in v13: the tabs were reorganised. What used to be MAIN is now DEVICE (and gained the
        storage card); WI-FI and USB HOST became two destinations inside CONNECTIONS; the EDITOR tab
        was born (theme, language and auto-save); and BACKUP became MAINTENANCE, now with the UPDATE
        card at the top.
Tabs on this page: DEVICE · CONNECTIONS · EDITOR · MAINTENANCE

9.1. DEVICE Tab (hardware and storage)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › DEVICE
Purpose: Identify the hardware, choose the language and access system utilities.
How to:
1. Check/adjust the Model — it must match your physical board.
2. Choose the editor's language.
Fields and items:
- MODEL (family + variant) (selection)
  Description: Family (BFMIDI 1/2/3) and variant (number of switches + size). It defines the pins,
             display and available features. Changing it restarts the controller. Only change it if
             you really swapped boards.
- SW6 = SW Global (switch)
  Description: (NANO models only.) Turns SW6 into the SW Global footswitch (a fixed function,
             outside the presets). Preset 6 no longer exists on these models. Restarts when changed.
- Remapping (rotation) (selection)
  Description: (MICRO models only.) Rotates the screen by 0/90/180/270° and remaps the footswitches
             accordingly — so you can mount the pedal in any orientation. Restarts when changed.
- Hardware test (action)
  Description: A 10-second diagnostic per category: LEDs (color sweep), Display (screen patterns)
             and MIDI (sends test messages). At the end, the active preset is restored.
- STORAGE (status)
  Description: It came from the backup tab in v13 and now lives here, next to the hardware. It shows
             how much internal memory is in use, split by category: presets, images, icons and
             what's left free.
             The limits depend on the model. The newer boards (ESP32-S3 line, such as the BFMIDI-3
             8SW+ and the NANO+ V2) have much more room: twice the image and icon slots, and far
             more headroom for content. If a bar fills up, delete media you don't use or simplify
             presets.
Notes:
- Wrong model = swapped switches and a screen with no image. If the pedal "went crazy" after you
   changed this, go back to the correct model.

9.2. CONNECTIONS › WI-FI Tab
~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › CONEXÕES › WI-FI
Purpose: Connect the editor to the controller and, if you wish, put the controller on your
          home/studio WiFi network (STA mode).
How to:
1. Turn on the pedal's WiFi: it turns on by itself when you power up the controller (and turns off
   after 90 s with no one connected). To turn it on/off manually with your foot, set up a combo with
   the WIFI ON/OFF action in GLOBAL › BANKS.
2. First connection: join the BFMIDI_WIFI network (password bfmidi@editor) and open
   http://192.168.4.1 — the Connection state card shows which scenario you are in.
3. To use it on your network: tap SCAN, pick the network from the list, type the password and tap
   CONNECT.
4. Once connected, go to http://bfmidi.local or the IP shown on the pedal's screen — without
   switching networks on your phone/laptop.
Fields and items:
- Connection state (status)
  Description: An educational card with the 4 possible scenarios, the current one highlighted: no
             WiFi (connect to the BFMIDI_WIFI network, password bfmidi@editor, and go to
             http://192.168.4.1), direct AP (your device on the pedal's network), router (pedal on
             your home network — go to http://bfmidi.local or the IP on the display) and USB (cable,
             via Web Serial).
- Connection status (status)
  Description: A summary of the current mode: AP only · 192.168.4.1 when the pedal is only on its
             own network, or the network name + IP when connected to your router (STA). The badge in
             the card's corner shows AP · OFFLINE or STA · ONLINE.
- SSID (network) (selection)
  Description: The target WiFi network. Pick it from the list filled in by SCAN or use "Type network
             name (hidden)" for hidden networks.
- Password (password)
  Description: Password of the chosen network. It is stored in the controller's protected memory (it
             survives updates). When a password is already saved, the field shows saved.
- SCAN (action)
  Description: Searches for nearby networks. Available only when you are connected via AP or USB —
             in STA the scan would drop the very connection you are using.
- CONNECT (action)
  Description: Applies and saves the credentials. On failure, the warning distinguishes wrong
             password from network out of range. Only 2.4 GHz networks are supported (a chip
             limitation).
- Nearby networks (list)
  Description: The scan result with signal strength (bars), dBm and a padlock (protected network).
             Tapping a network fills the SSID field automatically.
Notes:
- A weak signal is the most common cause of "I see the network but it won't connect" — move the
   pedal closer to the router to set it up.
- The WiFi turns off by itself after 90 seconds with no clients. It comes back when you restart the
   controller — or instantly, if you have a combo set to the WIFI ON/OFF action.
- Safari/iPhone does not support the USB connection (Web Serial) — use WiFi on iOS.

9.3. CONNECTIONS › USB HOST Tab
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › CONEXÕES › USB HOST
Purpose: Control the USB Host module (the second chip) that lets you plug USB devices straight into
          the controller: multi-effects units, MIDI keyboards, dongles. The BFMIDI-2 ship with the
          standard USB Host (forwards the device's MIDI); the BFMIDI-3 with the USB Host Plus, which
          adds the Tonex mode, reverse MIDI/Control Host and Bluetooth (features marked below).
How to:
1. The status card shows what is plugged in (manufacturer/product) and the module's health.
2. Choose the mode according to the connected device.
Fields and items:
- USB Host (status) (status)
  Description: Manufacturer and product of the connected USB device, the module's state and the last
             communication. The refresh button forces a fresh read.
- Mode (TONEX ONE / USB HOST) (selection)
  Description: USB HOST: a generic mode — whatever MIDI arrives is forwarded (this is what the
             BFMIDI-2's standard USB Host does). TONEX ONE (USB Host Plus / BFMIDI-3): a dedicated
             mode to control the IK Tonex One.
- MODULE UPDATE MODE (action)
  Description: To update the USB Host module's firmware you must put it in forced update mode. Step
             by step:
             1. Connect a USB cable between the controller's USB Host port and your computer.
             2. Open the editor over WiFi (not over the cable) and come to this tab.
             3. Click put USB Host into download mode.
             4. Then use the updater on the bffx.com.br page to flash the new firmware.
             Available only on BFMIDI-3 or higher models.
- MIDI filter (selection)
  Description: OMNI (passes everything) or a specific channel 1–16 — filters the MIDI coming from
             the connected USB device.
- BLE keyboard (switch)
  Description: (USB Host Plus / BFMIDI-3.) Enables Bluetooth keyboard support on the host module
             (for page/control accessories).
- MIDI BFMiDi (reverse + Control Host) (group)
  Description: (USB Host Plus / BFMIDI-3.) Lets a device plugged into the USB Host control the
             controller: PC 0–59 calls up the presets (A1–J6) and CC 81–85 navigates (bank up/down,
             preset up/down, exit LIVE). It also forwards the received MIDI ("reverse"). Choose the
             listening channel.
Examples:
- Teclado controla o pedal: teclado MIDI USB plugado no host mandando PC 0–5 = troca os presets
   A1–A6 da controladora.
Notes:
- The cards on this tab (except the status) appear only on BFMIDI-3 models.

9.4. Update (UPDATE EVERYTHING)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › MAINTENANCE — UPDATE
Purpose: Keep the controller up to date without downloading anything by hand. The card checks by
          itself when you open the tab and, when something is new, a single button updates firmware
          and editor together.
How to:
1. Open SYSTEM › MAINTENANCE. The card is the first on the tab and starts checking right away — you
   don't have to go looking for updates.
2. Read the status banner: UPDATE AVAILABLE, BFMIDI UP TO DATE or NOT CHECKED (when the device
   running the editor has no internet).
3. If there's something new, tap UPDATE EVERYTHING and follow the phases on screen. Do not unplug
   the cable during flashing.
4. When it finishes, the pedal restarts by itself with the new firmware and editor.
Fields and items:
- Status banner (status)
  Description: UPDATE AVAILABLE — a new version is out. BFMIDI UP TO DATE — you're on the latest.
             CHECKING… — querying. NOT CHECKED — the check couldn't run (the device running the
             editor needs internet); it isn't an error, and the pedal keeps working normally.
- UPDATE EVERYTHING (action)
  Description: A single button, on purpose: it handles the firmware (the pedal's program) and the
             editor (this screen) in one pass, in the right order. There's no updating one without
             the other.
             The one downloading from the internet is your browser, not the pedal — so the pedal
             doesn't need internet, only the device where the editor is open.
- Over the USB cable (path)
  Description: Connected over the cable, the editor writes everything in a single session
             (bootloader, firmware and the whole editor). The pedal restarts into flashing mode
             midway and the browser asks you to authorize the new port — that's expected: click and
             allow.
             Careful: this path replaces the pedal's entire content. Presets, images and icons
             return to the factory package — back up first.
- Over your network (no cable) (path)
  Description: With the pedal connected to your router (STA mode) and on models that have an update
             partition, you can update with no cable at all — and then your presets, images and
             icons are untouched.
             This path doesn't exist in AP mode (the pedal's own network) nor over the cable: in
             those cases the editor uses full flashing.
- Phases shown on screen (progress)
  Description: Downloading firmware → verifying file → releasing the port → putting the pedal in
             flashing mode → flashing → waiting for the pedal to come back → confirming the editor
             installation. During the upload the pedal's screen freezes — that's normal.
Notes:
- Very old pedal? A pedal predating the versioning system is treated as outdated (never as "up to
   date"): the card shows the published version and offers cable flashing.
- In the Android app, the editor screen is updated by the app itself (via the APK); here you update
   the pedal's firmware.
- Take a full backup before any cable update — it takes seconds and saves you from losing presets.

9.5. MAINTENANCE Tab (backup and data)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › MAINTENANCE
Purpose: Export and import all presets (with images and icons), erase data and track memory usage.
How to:
1. Export: generates a backup file with the 60 presets (and, if checked, the images and icons).
2. Import: choose a backup file; the controller writes everything and restarts.
3. Check the storage card now and then so you don't blow past the limits.
Fields and items:
- Include images and icons (switch)
  Description: Checked (default), the backup also carries the background images and the uploaded
             icons — the file gets bigger, but the restore brings the pedal back exactly as it was.
- BACKUP (action)
  Description: Downloads a file with all the presets (name, MIDI, switches and display, both
             layers). It works over WiFi and over USB. The status pill below shows the progress.
- RESTORE (action)
  Description: Restores a backup. The media are written first, then the presets, and the controller
             restarts at the end. It accepts backups from earlier versions.
- Danger Zone (erase data) (destructive action)
  Description: ERASE PRESETS resets the 60 presets to the factory default; ERASE GLOBAL CONFIG
             restores the global settings (LEDs, banks, global MIDI…) without touching the presets.
             Both ask for confirmation and have no undo — export a backup first.
- STORAGE (now under DEVICE) (status)
  Description: Moved in v13: this card now lives in SYSTEM › DEVICE, next to the hardware.
             It shows internal memory usage per category — Presets, Images, Icons and free space —,
             each with used/free/total. If any bar fills up, remove media or simplify presets. The
             limits depend on the model: the newer boards (ESP32-S3) have far more room for images
             and icons than the earlier ones.
Examples:
- Antes de atualizar o firmware: exporte um backup completo com mídias — qualquer imprevisto,
   importa de volta e segue o baile.
Notes:
- The global config (WiFi, model, LEDs) is not part of the preset backup — by design, it survives in
   the device's protected memory.

9.6. BFMiDi Bluetooth
~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › CONNECTIONS › USB HOST — BLUETOOTH
Purpose: Turn on the controller's Bluetooth and choose what it does: become a keyboard, become a
          wireless MIDI interface, or go looking for a Bluetooth pedal to gain extra footswitches.
How to:
1. In SYSTEM › CONNECTIONS › USB HOST, turn on the BFMiDi Bluetooth card.
2. Choose the function: KEYBOARD, MIDI or PEDAL. The choice changes who searches for whom.
3. Pair from the other device — the controller advertises itself as BFMiDi.
Fields and items:
- KEYBOARD (function)
  Description: The controller becomes a Bluetooth keyboard. CCs turn into keys and shortcuts on the
             phone or computer — for driving apps that don't speak MIDI: sheet-music apps,
             recorders, slide decks.
- MIDI (function)
  Description: The controller becomes a Bluetooth MIDI interface named BFMiDi and waits. Use it when
             the other device is the one searching — phone, tablet, computer/DAW, or another pedal
             in central mode.
- PEDAL (function)
  Description: The other way around: the controller searches on its own for a Bluetooth MIDI pedal
             that is advertising (blinking) and connects to it. Use it to gain wireless footswitches
             — M-Vave Chocolate, X-Vive MD1.
- Who searches for whom (concept)
  Description: It's the only confusing part here, and the card sums it up in one line: in KEYBOARD
             and MIDI the controller waits (the other device searches for it); in PEDAL the
             controller searches (it finds the pedal and connects).
Notes:
- Bluetooth lives in the USB Host module, so the card only appears on models that carry it.

9.7. EDITOR Tab (theme, language and saving)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › EDITOR
Purpose: The preferences of the app itself — not of the pedal. Appearance, interface language and
          whether changes save themselves.
How to:
1. Choose the theme (light or dark) — it applies to this screen, on the device you're using.
2. Choose the interface language: Portuguese, English or Spanish.
3. Decide whether you want auto-save on.
Fields and items:
- Theme (light / dark) (selection)
  Description: The editor's appearance. It's a preference of the device where you opened the screen
             — changing it here doesn't touch the pedal's display.
- Interface language (selection)
  Description: Portuguese, English or Spanish. It affects the editor's labels and each card's
             explanatory notes. The pedal's display stays in English.
- Auto save (switch)
  Description: On, the editor waits a moment after each change and saves by itself, without you
             touching SAVE. Off, nothing is stored until you tap SAVE — and leaving the preset
             discards the change.
Notes:
- These three preferences live on the device running the editor, not on the controller: opening the
   editor on another phone may show a different theme and language.

9.8. Three backup scopes (all, bank or preset)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: SYSTEM › MAINTENANCE — BACKUPS
Purpose: Not every backup has to be of the whole pedal. There are three cards, from the widest to
          the narrowest scope — and the middle one is what you use to carry a set list from one
          pedal to another.
How to:
1. Whole pedal: all 60 presets, plus images and icons, plus the GLOBAL configuration. This is the
   backup you take before updating.
2. One bank (6 presets): carries only the images and icons that bank actually uses. Perfect for
   swapping a set with someone else.
3. A single preset: the smallest scope, to copy one specific song.
Fields and items:
- Whole-pedal backup (file)
  Description: Produces a file with everything: all 60 presets (10 banks × 6), the images, the icons
             and the GLOBAL configuration. This is what you keep before updating or lending the
             pedal.
- Single-bank backup (set list) (file)
  Description: Saves the 6 presets of one letter and only the media they use — the file stays small.
             On restore, the target bank is replaced entirely: slots missing from the file return to
             default. This is the right scope for carrying a band's set to another pedal.
- Single-preset backup (file)
  Description: The smallest scope: a single preset, with the media it references. Use it to copy one
             specific song to another bank, another pedal, or to keep a version before
             experimenting.
Notes:
- All three scopes produce and read the same kind of file — what changes is how much goes inside.
- The GLOBAL configuration only travels in the whole-pedal backup: it describes the machine (model,
   colours, controls), and applying it to different hardware would configure the wrong board.

TOPIC 10 - ADVANCED FEATURES

Summary: CC navigation commands, physical combos, firmware updates and tools.
Introduction: Features to get even more out of the controller: special commands that navigate the
        pedal itself, the physical footswitch combos, and the update and diagnostic tools.

10.1. Special commands (CC ≥ 128)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: CC SELECTOR — » OPTIONS AT THE END OF THE LIST
Purpose: In the switches' CC selectors there are options marked with » that don't send MIDI — they
          command the controller itself. Use them to create navigation footswitches inside presets.
How to:
1. In a switch's CC selector (SINGLE, STOMP etc.), scroll down to the » options at the end of the
   list.
2. In SINGLE and STOMP modes the channel is optional for commands; in the others, select any
   channel.
Fields and items:
- » UP BANK (128) (command)
  Description: Advances to the next enabled bank (A → B → …).
- » DOWN BANK (129) (command)
  Description: Goes back to the previous bank.
- » UP PRESET (130) (command)
  Description: Calls the next preset in the bank.
- » DOWN PRESET (131) (command)
  Description: Calls the previous preset.
- » OUT LIVE (132) (command)
  Description: Exits LIVE mode and returns to BANK mode.
- » TO LAYER (133) (command)
  Description: Switches between Layer 1 and Layer 2 of LIVE mode — the two “pages” of functions each
             preset can have. It only makes sense inside LIVE.
- » SW_LIVE (134) (command)
  Description: Does the same as the LIVE button on boards that have one: enters and exits LIVE mode.
             It's the command that guarantees a way back on boards without a dedicated button (NANO,
             MICRO, 6SW+).
- » UP / DOWN BANK STANDBY (135 / 136) (external command)
  Description: Exclusive to the External SW1 / External SW2 cards (the external jack footswitches).
             They move through banks in preview, without changing the sound, and wait for a preset
             footswitch to confirm.
             They're how you gain preview navigation using the external buttons, without spending
             any of the controller's six footswitches.
Examples:
- Pedal de 4 switches sem botão LIVE: SW4 em SINGLE com » OUT LIVE — um jeito de sair do LIVE sem
   combo.
Notes:
- Special commands fire only on the foot tap in LIVE (never when the preset is called).

10.2. Foot shortcuts — LIVE button and combos
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: FOOT SHORTCUTS
Purpose: Everything your foot can do without going through the editor: the LIVE button on boards
          that have one, and two-footswitch combos — which in v13 stopped being fixed and became
          configurable.
How to:
1. Combos are configured in GLOBAL › BANKS › Footswitch Combos — see the dedicated card on that
   page.
Fields and items:
- LIVE button (boards with a dedicated button) (physical button)
  Description: On boards with a separate LIVE button (the 7S, for example): tap = enter LIVE / cycle
             the Layer, if enabled / exit. Hold = exit LIVE straight away, from any layer.
             This button isn't configurable — it's the fixed way in and out of LIVE mode on those
             boards.
- Combos — what changed in v13 (change)
  Description: Up to v12 there were two fixed combos, the same on every pedal: SW2+SW3 turned WiFi
             on and, on boards without a LIVE button, SW1+partner entered LIVE mode.
             In v13 they became nine free pairs, each with whatever action you choose — in GLOBAL ›
             BANKS › Footswitch Combos.
             Practical consequence: on a factory pedal no combo comes configured. Those who updated
             from an earlier version get the two old ones automatically; those starting on v13 build
             their own.
- How the pedal decides it's a combo (detail)
  Description: The action fires the moment the second foot lands — it doesn't wait for you to lift.
             While both are pressed, those switches' individual gestures are swallowed, so the combo
             doesn't fire two things at once.
             A footswitch taking part in an active combo gets a slightly slower long click,
             precisely to give you time to form the pair.
- I lost WiFi access — now what? (help)
  Description: WiFi turns itself off after 90 seconds with nobody connected. If you don't have a
             WiFi combo configured (yet), there are two ways in:
             1. Power the controller off and on — WiFi comes up at boot, giving you 90 s to connect.
             2. Connect over the USB cable to a computer with Chrome or Edge — it doesn't depend on
             any radio.
             Once inside the editor, set a combo to the WIFI ON/OFF action so you don't go through
             this again.
Notes:
- Combos apply in BANK mode. The only exception is the enter/exit LIVE combo, which keeps working
   inside LIVE — otherwise, on boards without a dedicated button, there would be no way back by
   foot.

10.3. Update — how it works under the hood
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: THE TWO PIECES AND THE TWO PATHS
Purpose: The user-facing steps are in SYSTEM › MAINTENANCE. Here are the details for those who want
          to understand what happens — the two pieces being updated, the two possible paths and what
          each one preserves.
How to:
1. In practice you tap UPDATE EVERYTHING and wait. The rest of this page is explanation, not a task.
Fields and items:
- FIRMWARE (piece)
  Description: The program running inside the controller: it reads the footswitches, sends the MIDI,
             draws the screen and lights the LEDs. All the footswitch-mode logic lives here.
- WEB EDITOR (piece)
  Description: This screen — the app the controller serves over WiFi. It's stored in a separate area
             of the pedal's memory.
             The two pieces travel together: a new editor may depend on features that only exist in
             the new firmware. That's why there's one button, not two.
- Path 1 — over the USB cable (path)
  Description: Works on any model and is the rescue path: even a pedal with very old firmware comes
             back to life this way. It needs a computer with Chrome or Edge (Safari has no serial
             port access).
             It writes everything in one session. Midway the pedal restarts into flashing mode and
             shows up as a new port — the browser will ask for authorization again; that's expected.
             It replaces all content: presets, images and icons return to the factory package. Back
             up first.
- Path 2 — over your network (no cable) (path)
  Description: Available on newer models, which have a reserved area to receive the update, and only
             with the pedal connected to your router (not to its own network).
             The big advantage: your presets, images and icons are untouched. The pedal writes the
             new version to the reserved area and starts using it on the next boot; if something
             goes wrong midway, it falls back on its own to the version that was working.
- Who downloads from the internet (detail)
  Description: It's your browser, not the pedal. That's why the controller doesn't need internet
             access — the phone or computer running the editor does.
             It's also why, connected only to the pedal's network (AP mode), the card may show NOT
             CHECKED: your device is on the pedal's network, which doesn't lead to the internet.
Notes:
- Numbering goes 13.0, 13.1 … 13.4 and so on — it isn't decimal: 13.10 comes after 13.9.
- Firmware and editor show the same version. If they differ, the installation was left half-done —
   run the update again.

10.4. USB MIDI monitor (external tool)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Related screen/preview: USB MIDI MONITOR
Purpose: A standalone page that shows, live, all the MIDI messages the pedal sends over USB — to
          check and debug what's going out.
How to:
1. Open the USB Monitor page in Chrome, Edge or Opera and accept the MIDI permission.
2. Select the "BFMiDi" input in the menu and tap the pedal's footswitches.
Fields and items:
- PAUSE / RESUME (button)
  Description: Freezes the list without disconnecting — to read at your leisure.
- CLEAR (button)
  Description: Empties the history.
- COPY (button)
  Description: Copies the events as text, ready to paste into a message.
- Show Clock / Active Sense (switch)
  Description: Clock messages are filtered by default (they flood the screen). Enable only if you
             need to see them.
- Collapse repeated (switch)
  Description: Consecutive identical messages become a single line with an ×N counter.
Notes:
- The tool only receives MIDI — it doesn't send anything to the pedal.
